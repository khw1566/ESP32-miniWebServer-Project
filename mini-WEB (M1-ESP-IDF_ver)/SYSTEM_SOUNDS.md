# M1 스피커 알림음

ESP32-2432S028R의 스피커 커넥터에 연결된 스피커를 GPIO26 DAC로 구동합니다.
동봉된 `esp32 2432s028 스피커 시작동` 예제의 핀을 따릅니다.
GPIO25는 터치 클럭이므로 오디오에 사용하지 않습니다.
SD카드, WAV/MP3 파일, 인터넷 다운로드 없이 하드웨어 코사인 파형으로 재생합니다.

| 상황 | 멜로디 | 같은 알림 최소 간격 |
| --- | --- | --- |
| 부팅 초기화 | 도5-미5-솔5-도6 | 부팅당 1회 |
| Wi-Fi IPv4 주소 획득 | 미5-시5 | 5초 |
| 연결됐던 Wi-Fi가 끊김 | 솔5-도5 | 15초 |
| 최초 Wi-Fi 연결 재시도 소진 | 솔4-솔4-도4 | 30초 |
| 설정용 SoftAP 시작 완료 | 도5-도5-솔5 | 5초 |
| HTTP 서버 시작 완료 | 도5-솔5 | 1초 |
| HTTP 서버 정지 완료 | 솔5-솔4 | 1초 |
| 외부 도메인 중계 응답 성공 | 솔5-시5-레6-솔6 | 60초 |
| HTTP 서버 시작/정지 오류 | 미4-미4 | 5초 |

부팅음은 로그 초기화 후 재생하며 전체 서비스 준비 완료를 뜻하지 않습니다.
Wi-Fi는 AP 연결만으로 성공 처리하지 않고 IPv4 주소 획득 시 알립니다.
의도적인 Wi-Fi 해제에는 끊김음을 재생하지 않습니다.
외부 도메인은 중계 서버의 poll HTTP 200/204 확인 후 알립니다. 모든 정기 poll에서
소리가 나지는 않습니다. 이는 외부 휴대폰에서 공개 페이지를 실제 열어본 검증과는 별개입니다.
AI 처리 후 중계 복구도 상태 전환이며, 도메인 알림의 60초 제한을 적용합니다.

## 음량과 사용 설정

홈 화면 상단의 화면 끄기 버튼 바로 왼쪽에 음량 토글이 있습니다.
누를 때마다 `무음 → 음량 1 → 음량 2 → 음량 3 → 음량 4 → 무음`으로 순환합니다.
1=-18dB, 2=-12dB, 3=-6dB, 4=최대 진폭입니다. 기본은 음량 1입니다.
음량을 켜거나 바꾸면 짧은 확인음이 나오며, 무음으로 바꿀 때는 확인음을 내지 않습니다.
재생 중 무음으로 바꾸면 현재 음표(최대 200ms)가 끝난 후 멈춥니다.
선택한 값은 작업 태스크가 NVS에 저장하고 다음 부팅음부터 적용합니다.
저장 실패 시 기존 음량을 유지하고 화면 하단에 실패를 표시합니다.

출고 기본은 알림음 사용, DAC 진폭 1/8(-18dB)입니다. 실제 음량은 스피커와 보드 앰프에 따라
달라집니다. `idf.py menuconfig`의 `M1 speaker notifications`에서 다음을 설정합니다.

- `Enable GPIO26 speaker notification melodies`: 전체 알림 사용/해제.
- `DAC attenuation`: 3=-18dB(기본), 2=-12dB, 1=-6dB, 0=최대 진폭.

`DAC attenuation`은 저장된 음량이 없을 때만 초기값으로 사용합니다.
전체 알림을 빌드 설정에서 끄면 화면의 음량 버튼도 비활성화됩니다.

별도 낮은 우선순위 태스크(스택 3072바이트), 최대 6개 이벤트 큐로 순차 재생합니다.
화면·Wi-Fi·HTTP 호출자는 재생을 기다리지 않습니다. 큐가 가득 차면 새 알림을 버리고
해당 알림의 반복 제한은 유지합니다. 멜로디는 각 1초 미만이며, 메모리에 음원 버퍼를
보관하지 않습니다. 음표마다 작은 DAC 핸들을 할당·해제하며 오류 시 이후 재생을
중단하고 서비스는 계속 실행합니다. 새 watchdog/고빈도 ISR은 추가하지 않습니다.

## 검증 범위와 실물 확인

ESP-IDF 5.5.5의 로컬 DAC 헤더·드라이버, ESP32 타깃, 핀 충돌, CMake 등록을 대조했습니다.
이 결과는 펌웨어 컴파일이나 실물 재생 검증이 아닙니다. 기존 build 메타데이터에는
과거 프로젝트 경로가 남아 있고 새 소스도 아직 없습니다.

프로젝트 지침에 따라 빌드·업로드는 사용자가 ESP-IDF 터미널에서 수행합니다.

```powershell
Set-Location 'C:\Users\work\Desktop\Mini WebServer\mini-WEB (M1-ESP-IDF_ver)'
idf.py -B build-m1-sounds build
idf.py -B build-m1-sounds -p COM번호 flash monitor
```

기존 빌드 디렉터리를 보존하도록 새 빌드 경로를 사용합니다. 첫 부팅에서 부팅음,
저장 Wi-Fi 연결음, 서버 시작음, 출고 등록된 도메인의 연결음을 확인하세요.
서버 정지/시작, 공유기 끊김/복구, 잘못된 Wi-Fi 비밀번호, SoftAP 전환도 확인하고,
터치·웹 응답이 유지되는지 확인하세요. 반복적인 도메인 재접속은 60초 제한으로
무음일 수 있습니다. 소리가 없으면 스피커 커넥터와 `M1_SOUND` 로그를 확인하세요.
