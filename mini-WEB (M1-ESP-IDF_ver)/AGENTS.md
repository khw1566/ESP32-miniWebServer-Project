# M1 온보드 화면 규칙

- 사용자 요구: 모든 온보드 화면에서 버튼과 조작 요소가 240 x 320 화면 안에 완전히 보이도록 구성한다.
- 화면 전체의 세로 스크롤에 조작 버튼을 숨기지 않는다. 목록이 길면 페이지를 나누고 이전/다음 버튼을 고정한다.
- 키보드가 열려도 입력란, 연결 버튼, 홈 버튼, 목록 복귀 버튼이 잘리지 않도록 별도 영역을 확보한다. 입력 중 검색/연결/홈은 표시한 채 비활성화하고 목록 복귀 후 다시 활성화한다.
- 비밀번호 입력을 마스킹하지 않는다. 사용자의 기본 키보드 복원 요청에 따라 영문·숫자 키를 한 화면에 모두 표시하고 문자 페이지 넘김은 사용하지 않는다. QWERTY와 숫자 행은 최대 10개 키를 사용한다. 특수문자 전환과 목록 복귀는 문자 키와 분리된 고정 버튼으로 제공하며 입력은 터치 해제 시 한 번만 확정한다.
- 제목 28px, 본문 264px, 상태 표시 24px를 기준으로 구성한다. 긴 문자열은 조작 버튼을 밀어내지 않도록 생략 표시한다. 실제 데이터는 생략하지 않는다.
- 새 화면 및 오류 화면도 같은 규칙을 적용한다. LCD 방향 설정과 터치 좌표 반전은 독립적으로 관리한다.
- 상위 저장소의 컴파일/업로드 금지 지침을 따른다.
