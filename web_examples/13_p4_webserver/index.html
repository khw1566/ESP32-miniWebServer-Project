05 / A FEW GOOD QUESTIONS.

궁금한 점,
미리 살펴보세요.

P4만으로 Wi-Fi에 연결하나요?

이 프로젝트에서는 ESP32-C6를 무선 통신 칩으로 사용합니다. P4와 C6를 ESP-Hosted로 연결하며, 두 칩의 펌웨어 버전이 호환되어야 합니다.

서버 IP를 직접 지정할 수 있나요?

네. 설정 화면에서 DHCP 또는 고정 IPv4를 선택할 수 있습니다. 고정 주소는 IP·게이트웨이·서브넷 마스크·DNS를 입력합니다. 설정용 SoftAP 주소는 192.168.4.1로 유지됩니다.

인터넷이 없어도 웹사이트를 열 수 있나요?

서버와 같은 로컬 네트워크에 연결되어 있으면 내부 웹 파일을 열 수 있습니다. 이 소개 페이지의 그래픽도 외부 라이브러리 없이 표시됩니다. 외부 AI API를 사용하는 기능에는 인터넷이 필요합니다.

유선 LAN이나 카메라도 지원하나요?

현재 무선 펌웨어에서는 RJ45 네트워크, 카메라, LCD, 오디오를 활성화하지 않습니다. 이 소개 페이지는 현재 구성에 포함된 웹서버·Wi-Fi·저장소 기능을 설명합니다.

처음에는 어떻게 접속하나요?

보드가 만든 Mini-WebServer-Setup Wi-Fi에 연결하고 http://192.168.4.1/setup을 여세요. 공유기 정보를 저장하면 보드가 재시작합니다. 이후 같은 공유기에 연결해 서버 주소로 접속하세요. 연결에 실패하면 SoftAP 설정으로 돌아옵니다.
