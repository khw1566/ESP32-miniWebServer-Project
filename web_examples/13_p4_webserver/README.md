# P4 웹서버 소개 페이지

`index.html` 하나를 P4 관리자 파일 관리에서 업로드하면 됩니다. 외부 이미지·폰트·라이브러리가 필요 없습니다.

저장소 루트에서 `node tools/embed_p4_home.cjs`를 실행하면 이 예제를 P4 첫 부팅용 페이지로 반영합니다. 로컬 호스팅 작업 폴더 `sites/p4-webserver/dist/index.html`이 있는 환경에서는 그 파일을 원본으로 사용해 예제도 함께 갱신합니다. GitHub에서 새로 내려받은 환경에서는 이 폴더의 `index.html`을 원본으로 사용하므로 별도 호스팅 폴더가 필요 없습니다.

픽셀 3D 보드 회전, 색상 전환, 애니메이션 정지, 연결 단계 설명, 기능 목록, 하드웨어 사양, FAQ를 포함합니다. 실제 하드웨어 동작 상태를 조회하는 대시보드가 아닌 소개 페이지입니다.

## 편집과 적용

외부 폰트·이미지·JavaScript 라이브러리가 필요 없는 단일 HTML입니다. 보드 그래픽은 실제 회로 배치를 재현한 도면이 아닌 개념 모델입니다. 브라우저의 동작 줄이기 설정을 반영하며 화면 밖에서는 보드 렌더링을 멈춥니다.

기존 웹 파일이 저장된 보드는 관리자에서 `index.html`만 업로드하면 됩니다. 최초 설치용 펌웨어에 넣을 때는 위 생성 명령을 실행한 후 사용자가 펌웨어를 빌드·업로드합니다.

보드에서 접속하면 설정·관리 링크는 해당 보드의 `/setup`, `/admin`으로 이동합니다. 외부 미리보기에서는 설정망 주소 `192.168.4.1`로 이동하므로 먼저 보드의 `Mini-WebServer-Setup` Wi-Fi에 연결하세요.
