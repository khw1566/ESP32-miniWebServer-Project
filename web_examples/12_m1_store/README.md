# Mini WEB M1 판매 페이지 예제

ESP32-2432S028(M1) 보드와 Mini WEB 시스템을 소개하는 판매 페이지입니다. 그림은 움직이지 않는 WebP이고, 움직임은 HTML과 CSS 층이 그림 위에서 만듭니다. 외부 폰트, 라이브러리, CDN을 사용하지 않아 SoftAP처럼 인터넷이 없는 환경에서도 그대로 표시됩니다.

| 파일 | 정적 그림 | CSS로 움직이는 부분 |
| --- | --- | --- |
| `index.html` | - | 반응형 판매 페이지 (기능, 사양, 시작 방법, 패키지, 질문) |
| `hero.webp` | 보드와 홈 대시보드 (투명 배경) | 신호 원, 보드 떠오름, Wi-Fi 막대, 서버 표시, RAM 막대, 터치, LED |
| `network.webp` | 스마트폰, 보드, 외부 도메인, 연결선 | 오가는 데이터 점, 보드 신호, 휴대전화 화면 |
| `qr.webp` | 접속 QR이 표시된 보드, 휴대전화 | QR 나타남, 스캔 선, 접속됨 표시 |
| `storage.webp` | SD카드, 파일 목록 | 사용량 원 그래프와 숫자, 파일 줄 차례로 등장 |
| `saver.webp` | 화면이 켜진 보드, 설명 문구 | 화면 꺼짐과 대기 점, RAM 여유 막대, 상태 문구, 터치 복귀 |

그림 5개는 합계 약 51 KiB입니다. 선명하게 보이도록 2배 해상도로 저장했습니다.
움직임은 화면에 보이는 그림만 재생하며, 기기에서 동작 줄이기를 켜면 멈춘 완성 화면을 보여줍니다.
가격과 구성은 예시이며 구매 버튼은 안내 문구만 표시합니다.

## 보드에 올리기

1. 관리자 페이지의 파일 관리에서 폴더 안의 `index.html`과 모든 `.webp` 파일을 같은 위치에 업로드합니다. README는 올리지 않아도 됩니다.
2. `index.html`을 메인 페이지로 지정하거나 `http://보드주소/index.html`로 접속합니다.

## 그림 다시 만들기

그림은 `tools/make_m1_store_webp.py`로 생성합니다. CSS 층의 위치(`--x`, `--y`, `--lw`, `--lh`)는 이 스크립트의 그림 좌표와 같은 픽셀 단위이므로, 그림 배치를 바꾸면 `index.html`의 좌표도 함께 고쳐야 합니다. Pillow가 필요하며 한글은 Windows의 맑은 고딕을 사용합니다.

```powershell
python tools/make_m1_store_webp.py
```

## PC 미리보기

```powershell
python -m http.server 8790 --bind 127.0.0.1
```
