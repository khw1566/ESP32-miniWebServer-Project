Built for the edge

작은 보드에서 시작하는
독립형 웹 경험

정적 웹 호스팅부터 브라우저 관리까지 필요한 기능을 한 보드에 담았습니다. 외부 서버 없이 같은 네트워크에서 직접 제공할 수 있습니다.

01 / CONNECT

연결은 간단하게

초기 설정용 Wi‑Fi에 접속하면 설정 페이지가 열립니다. 주변 네트워크를 선택해 연결하고, 이후에는 공유기 네트워크에서 보드에 접속합니다.

02 / HOST

웹페이지를 보드에 저장

관리자 파일 관리에서 HTML, CSS, JavaScript와 이미지를 업로드해 운영할 수 있습니다. 업로드한 HTML을 첫 화면으로 지정할 수도 있습니다.

03 / MANAGE

브라우저에서 한눈에

메모리와 Wi‑Fi 상태, 가동 시간, 파일 저장공간을 확인하고 접속 QR 코드를 표시합니다. 펌웨어에 내장된 관리 화면으로 PC 없이 다룰 수 있습니다.

04 / AI ASSIST

AI로 페이지 만들기

AI 웹 도우미에서 페이지를 생성하고 파일을 보드 저장소에 적용할 수 있습니다. Gemini API 키와 인터넷 연결이 필요한 선택 기능입니다.

05 / LOCAL FIRST

내 네트워크에서 직접 제공

공유기에 연결하면 같은 네트워크의 휴대폰과 PC에서 접속할 수 있습니다. IPv6 외부 접속은 공유기 방화벽과 회선 환경에 따라 달라집니다.

06 / OPEN WEB

앱 설치 없이 열기

표준 브라우저에서 접속하는 웹 방식입니다. 화면은 모바일과 데스크톱에 맞춰 조정되며, 자체 제작한 예제 페이지도 함께 운영할 수 있습니다.
