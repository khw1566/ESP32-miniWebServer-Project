Mini WebServer S3 연동 예제 패키지

설치
1. 최신 펌웨어를 업로드하고 보드 관리자 > 파일관리에서 upload 폴더 안의 파일을 같은 위치에 업로드합니다. ZIP 파일 자체는 업로드하지 않습니다.
2. index.html을 메인 페이지로 지정합니다. 보드의 공유기 IPv4/IPv6 주소에서 허브와 예제 링크를 확인합니다.
3. 관리자 파일관리에서 원하는 HTML 파일을 메인으로 지정할 수도 있습니다.

C3 1.75 MiB LittleFS 파티션에 맞춰 cafe.webp, museum.webp, farm.webp를 사용하며 용량이 큰 원본 JPG는 패키지에서 제외했습니다.

예제 기능
C3 1.75 MiB LittleFS 파티션에 맞춰 cafe.webp, museum.webp, farm.webp를 사용하며 용량이 큰 원본 JPG는 패키지에서 제외했습니다.
- 3D 게임: game_3d.html은 외부 파일 없이 WebGL 1.0으로 렌더링합니다. 좌우 이동과 장애물 회피, 점수/최고 점수, FPS와 프레임 시간을 표시합니다. 보드에서 열어 WebGL 지원 여부와 렌더링 성능을 확인하세요.
- 카페: 메뉴 장바구니/수량/요청사항, Toss Payments 테스트 결제창, 결제 복귀 후 VISTA PaymentServer 승인 요청. 결제창에 VISTA 서버 LAN 주소(http://PC주소:5001)와 Toss 테스트 Client Key를 입력합니다. 결제 비밀키는 서버 환경에 설정하고 HTML에 넣지 마세요. Toss 결제에는 인터넷이 필요하며 서버 승인 응답이 없으면 성공 처리하지 않습니다.
- 박물관: 전시별 해설은 브라우저/기기의 Speech Synthesis 음성으로 재생됩니다. 한국어 음성 지원은 기기 설정에 따라 다릅니다. MP3 스트리밍 파일은 포함하지 않습니다.
- 스마트팜/포털 수치와 제어는 실제 센서/설비 연결이 아니라 브라우저 시연입니다. 2048과 테트리스는 브라우저 게임입니다.
- C3 Mini 소개 페이지는 Wi-Fi, 웹파일 호스팅, 관리자 기능과 QR 접근 흐름을 설명합니다.

QR 생성과 관리자 기능은 보드에서 확인하세요. 허브의 일부 기능은 보드 API 또는 인터넷 연결을 필요로 합니다. 설정용 캡티브 포털에서 루트가 설정 화면이면 /index.html로 허브를 엽니다.
