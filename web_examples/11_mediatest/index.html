로드 확인은 브라우저에서 파일을 읽었다는 뜻입니다. SD 저장 위치와 애니메이션의 실제 움직임은 직접 확인하세요.

SD카드에서 테스트하기

  1. index.html과 미디어 네 개를 SD카드의 최상위에 복사합니다.
  2. 보드에 SD카드를 넣고 전원을 켭니다. 보드 주소의 /index.html로 접속합니다.
  3. 미디어를 하나씩 재생합니다. MP4는 재생 막대로 중간 위치로 이동해 보세요.
  4. 파일을 /media에 넣었다면 위의 파일 위치를 바꿉니다.

어떤 상태를 확인하나요?

  • GIF: 이미지 로드, 화면 크기, 반복 움직임.
  • MP4: 메타데이터, 실제 재생, 버퍼 대기, 탐색 완료.
  • 전송 확인: 파일 응답과 MIME, 16바이트 Range 요청. HTTP 206은 부분 응답입니다.
  • 오류가 나면 전송 확인을 누르세요. 정상 전송 후 재생 실패는 브라우저 코덱도 확인해야 합니다.
