# M3 스마트폰형 앱

2026-10-15 소스 변경입니다. 펌웨어 빌드, 새 PC 화면 렌더링, 보드 동작은 아직 확인하지 않았습니다.
기존 Wi-Fi, 관리자 비밀번호, 연결 키, 파티션과 OTA 슬롯은 유지합니다.

## 부팅 화면

M3 로고와 저장공간·Wi-Fi 시작 상태를 표시합니다. 서비스 준비 후 홈으로 전환합니다.
시작이 지연되면 12초 뒤 홈을 열어 설정에 접근할 수 있습니다. 웹 집중 모드는 기존처럼 화면을 켜지 않습니다.

## 파일 삭제·이동

파일 앱에서 항목을 길게 누르면 작업 메뉴가 열립니다. 짧게 누르면 기존 탐색·재생 기능을 사용합니다.

- 삭제: 삭제를 누른 뒤 같은 버튼을 한 번 더 눌러 확정합니다. 폴더는 비어 있어야 합니다.
- 이동: 기존 대상 폴더를 포함한 전체 경로를 입력합니다. 예: `/media/image.png`에서 `/widgets/photos/image.png`로 이동.
- 같은 저장장치 안에서 이동합니다. Flash는 루트 파일의 이름 변경을 지원합니다. Flash와 SD 사이 복사는 포함하지 않습니다.
- 기존 대상 파일은 덮어쓰지 않습니다. 상대 경로, 상위 폴더 탈출, 숨김 업로드 파일과 `.tmp` 파일은 거부합니다.
- 재생·녹음·갤러리 사용 중에는 작업을 거부합니다. 해당 작업을 종료하고 다시 시도하세요.

## 갤러리

홈의 갤러리 앱은 SD `/media`를 엽니다. 폴더를 탐색하고 파일을 선택합니다. 파일 앱에서 지원 이미지를 선택해도 갤러리를 엽니다.
이전·다음 버튼은 현재 목록 페이지의 지원 파일을 순환합니다. 다른 페이지는 목록으로 돌아가 탐색합니다.

| 파일 | 보드 직접 표시 |
| --- | --- |
| JPG/JPEG | 하드웨어가 지원하는 baseline JPEG |
| BMP | 기존 비압축 BMP 디코더가 지원하는 형식 |
| PNG | RGB/RGBA 등 LodePNG가 처리하는 PNG, 투명 배경은 검정으로 합성 |
| MJPG/MJPEG | 연속 JPEG 프레임, 초당 최대 10장, 무음 |
| AVI | 헤더에 MJPG 코덱이 있는 MJPEG AVI, 무음 |
| GIF | GIF87a/89a 직접 재생. 애니메이션은 프레임 지연에 맞춰 반복, 투명 영역은 검정 |
| WebP/HEIC/AVIF/TIFF | 아래 도구로 변환 |
| MP4 | H.264 Constrained Baseline + AAC-LC 직접 재생. 상세 제한은 아래 참조 |
| MOV/WebM/MKV | 아래 도구로 호환 MP4 또는 MJPG로 변환 |

이미지는 파일 4 MiB 이하, JPEG/PNG는 각 변 2048 이하이며 총 2,097,152 픽셀 이하입니다.
MJPEG 프레임은 256 KiB 이하입니다. 메모리가 부족하거나 손상된 파일은 오류로 표시합니다.
GIF는 SD에서 4 KiB씩 읽으며 프레임을 차례로 합성하므로 파일 크기와 프레임 수 제한이 없습니다.
화면 크기는 각 변 2048 이하, 총 2,097,152 픽셀 이하입니다. 단일 프레임 GIF는 정지 이미지로 표시합니다.
MP4는 최대 1920×1080의 progressive H.264 Constrained Baseline(레벨 4.2 이하), 4바이트 NAL 길이,
단일 SPS/PPS, B 프레임 없는 파일을 지원합니다. AAC-LC는 8–48 kHz, 모노/스테레오입니다.
오디오 트랙이 없는 MP4도 지원합니다. HEVC/H.265, Main/High Profile, 암호화·분할 MP4와
여러 영상/음성 트랙은 지원하지 않습니다. MP4 확장자가 같아도 내부 코덱에 따라 변환이 필요합니다.
파일 2 GiB 미만, 영상 4시간 이하, 트랙당 700,000 샘플 이하(60 fps 약 3시간, 48 kHz AAC 약 4시간),
moov 16 MiB 이하, PSRAM 인덱스 할당 16 MiB 이하, 영상 샘플 1 MiB 이하, 음성 샘플 8 KiB 이하로 제한합니다.
샘플은 SD에서 하나씩 읽으며 파일 전체를 메모리에 올리지 않습니다.
ESP32-P4에는 H.264 하드웨어 인코더만 있고 디코더는 없어 소프트웨어로 디코딩합니다.
Espressif 공개 수치는 640×480 약 25 fps, 1280×720 약 7 fps입니다. 디코딩이 늦으면 음성을 기준으로
최대 0.25초마다 늦은 화면을 갱신하고, 0.4초 이상 밀리면 현재 시각 이전의 최신 키프레임으로 건너뜁니다.
720p·1080p는 음성은 끊기지 않지만 화면은 낮은 fps로 표시되며, 부드러운 재생은 640×480 이하를 권장합니다.
단순 양수 trim 편집 목록은 최대 2초까지 지원하며 복잡한 편집 목록은 거부합니다.
재생 중 일시정지와 공용 음량 조절을 사용할 수 있습니다. 다른 오디오 재생·녹음 중에는
이를 멈춘 뒤 영상을 다시 엽니다. 앱을 나가면 재생을 취소하고 영상 작업 종료 후 자원을 해제합니다.
화면 갱신이 늦으면 표시 프레임을 건너뜁니다. 실기 FPS와 영상·음성 동기는 아직 확인하지 않았습니다.
AVI의 H.264/H.265 등 다른 코덱은 지원하지 않습니다.
EXIF 자동 회전과 PNG(APNG) 애니메이션 직접 재생은 포함하지 않습니다.

PC에 FFmpeg가 설치되어 있으면 프로젝트 폴더에서 실행합니다. 설치된 FFmpeg가 HEIC/AVIF 입력을 지원해야 해당 형식도 변환할 수 있습니다.

```powershell
python tools/prepare_gallery.py 'C:/Pictures/photo.webp' 'C:/Pictures/photo.png'
python tools/prepare_gallery.py 'C:/Videos/clip.mp4' 'C:/Videos/clip.mjpg'
python tools/prepare_gallery.py 'C:/Videos/phone.mp4' 'C:/Videos/phone-m3.mp4' --native-mp4
python tools/prepare_gallery.py 'C:/Pictures/animation.gif' 'C:/Pictures/animation.mjpg'
```

원본을 보존하고 기존 출력은 덮어쓰지 않습니다. 생성한 파일을 SD `/media`에 복사합니다.
`--native-mp4`는 최대 480×272, 15 fps, H.264 Baseline과 AAC-LC로 변환하며 30분으로 자릅니다.
FFmpeg의 `libx264`와 AAC 인코더가 필요합니다. 출력이 512 MiB를 넘으면 영상 길이를 줄이세요.
이 설정은 초기 검증용이며 보드에서 15 fps를 보장하지 않습니다.
영상 크기는 SD 용량에 영향을 주므로 짧은 영상으로 먼저 확인하세요.

MP4 구현은 `espressif/esp_h264` 1.4.1 소프트웨어 디코더와 기존 `esp_audio_codec` 2.3.0을
사용합니다. H.264 컴포넌트는 다음 사용자 빌드에서 의존성 관리자가 설치합니다.
새 디코더의 IRAM 배치와 내부 이중 작업은 비활성화합니다. 펌웨어 크기와 OTA 슬롯 적합성은
사용자 빌드에서 확인해야 합니다.

## 공학용 계산기

사칙연산, 괄호, 거듭제곱, 팩토리얼, 백분율, 삼각함수·역삼각함수,
제곱근, 자연로그·상용로그, 절댓값, 지수함수, `pi`, `e`, 직전 결과 `Ans`를 제공합니다.
`DEG` 버튼으로 `RAD`와 전환합니다. 함수는 닫는 괄호를 입력합니다. 예: `sin(30)+sqrt(81)^2`는 DEG에서 `81.5`입니다.
`-2^2`는 `-4`, `2^3^2`는 `512`입니다. 입력 192자, 중첩 24단계로 제한합니다.
0으로 나누기와 정의역 오류, 무한대 결과는 오류로 표시하고 직전 정상 결과를 유지합니다.

## 녹음 저장·복구

녹음 중 PCM을 반영한 뒤 WAV 헤더를 갱신하고, 기록한 바이트 수로 다음 쓰기 위치를 지정합니다.
종료 시 헤더, 동기화, 닫기, 이름 변경이 모두 성공해야 저장 완료로 표시합니다. SD 오류를 성공으로 숨기지 않습니다.
실패하면 화면에 저장 단계와 오류번호가 표시되고 `M3_RECORDER` 로그에도 남습니다.
이 변경의 실물 보드 오류 해결 여부는 새 펌웨어에서 재검증해야 합니다.

이미 남은 `.wav.part` 파일은 녹음을 멈춘 뒤 파일 앱 `/recordings`에서 길게 눌러 **미완료 WAV 복구**를 선택합니다.
PCM16/mono/16 kHz 헤더와 파일 크기를 검사하고 실제 데이터 길이로 WAV 헤더를 복구합니다.
동기화와 닫기가 성공하면 원래 `.wav` 이름으로 바꿉니다. 대상 파일이 있거나 데이터가 손상됐으면 원본을 유지합니다.
복구는 녹음 내용 자체의 무결성이나 전원 중단 직전의 누락된 샘플까지 보장하지 않습니다.

## 라디오

라디오 모양 아이콘과 세계·한국·일본 선택을 추가했습니다. 기존 세계 방송국 7개를 유지합니다.

- 한국: Big B Radio K-pop. 한국 음악 인터넷 방송이며 국내 지상파 전체 목록은 아닙니다.
- 일본: FM Setagaya, Big B Radio J-pop.

2026-10-15 세 주소에서 `HTTP 200`, `audio/mpeg`, MP3 프레임 바이트를 확인했습니다.
PC의 스트림 접근 확인이며 보드 오디오 출력 검증은 아닙니다. 지역 제한이나 서버 변경으로 접근이 달라질 수 있습니다.
검색한 CBS 주소는 HLS 재생 목록을 반환해 프리셋에서 제외했습니다. 현재 직접 MP3/ADTS AAC만 지원합니다.
사용자 URL에는 해당 코덱의 직접 스트림을 입력합니다.

주소 확인 출처: [Radio Browser API](https://api.radio-browser.info/),
[Big B Radio](https://bigbradio.net/), [FM Setagaya](https://fmsetagaya.com/).

호스트 검사는 C 제어 흐름과 파일·마이크·오디오 모의 환경을 사용합니다. 실제 디코더·SD·화면·오디오는 실행하지 않습니다.
사용자는 ESP-IDF 터미널에서 `idf.py build` 후 보드에 설치하고 기능을 확인합니다.
PC 시뮬레이터는 `tools/ui_sim/build.ps1`의 한국어·영어 실행으로 새 화면을 생성합니다.
시뮬레이터 갤러리 서비스는 모의 데이터이므로 이미지 디코딩·영상 재생의 증거로 사용하지 않습니다.
