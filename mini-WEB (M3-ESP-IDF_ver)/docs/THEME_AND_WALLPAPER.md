# 테마와 홈 배경화면
설정 앱은 화면, 테마, 소리, 시스템 탭으로 나뉘며, 테마 탭의 카드에서 스타일, 색상, 테두리, 모서리, 홈 배경화면을 바꾼다. 변경은 즉시 적용되고 마지막 변경 1.5초 뒤 NVS(`m3_device` 네임스페이스, `theme` 키, 16바이트, 버전 2)에 저장된다. 이전 12바이트 형식은 읽을 때 다크 스타일로 옮긴다. 저장값이 없거나 손상되면 기본 테마(시안 `#00E5EF`, 마젠타 `#F548BA`, 테두리 없음, 둥근 모서리, 오로라 배경)를 쓴다.

## 설정 항목
- 스타일: 다크(기존 화면), 화이트(밝은 배경과 흰 카드), 모던(무채색과 파란 강조, 보통 모서리), 클래식(세피아와 금색, 색상 테두리, 각진 모서리). 스타일은 배경, 카드, 글자, 입력칸, 키보드, 위험 버튼 색과 강조색, 테두리, 모서리, 배경화면을 한 번에 바꾸며 그 뒤 아래 항목으로 세부 조정한다.
- 기본 색상, 강조 색상: 견본 10색 또는 색상환 슬라이더. 슬라이더는 끄는 동안 미리보기만 바꾸고, 손을 뗄 때 전체 UI에 한 번 적용한다.
- 테두리: 없음, 은은하게(구분선 색 1px), 색상(기본 색상 1px, 60% 불투명도). 카드, 버튼, 목록 항목에 적용된다.
- 모서리: 둥글게, 보통, 각지게. 카드, 버튼, 목록, 입력칸, 세그먼트 버튼의 반경을 함께 바꾼다.
- 홈 배경화면: 어두운 정적 5종(오로라, 한밤, 노을, 바다, 흑백), 어두운 라이브 3종(별빛, 흐르는 빛, 물방울), 밝은 정적 1종(새벽), 밝은 라이브 3종(구름, 꽃잎, 빛망울). 밝은 배경에서는 홈 화면 글자가 어두워진다. 화이트 스타일은 구름으로 시작한다.
- 기본 테마로 되돌리기.

## 구현
- `main/m3_theme.c`: 테마 값 검증, 기본값, NVS 읽기·쓰기.
- `main/m3_wallpaper.c`: LVGL 도형과 그라디언트로 배경을 그린다. 이미지 자산이 없어 Flash 증가는 코드와 문자열 정도다.
- `main/m3_theme_ui.inc`: 설정 카드, 공유 스타일 갱신, 색상 변경 적용. `m3_ui.c`가 포함한다.
- `CYAN`, `MAGENTA`, `ON_ACCENT`와 중립색 `INK`, `SURFACE`, `TEXT` 등은 이제 런타임 변수(`ui_palette`)다. 정적 테이블 초기값으로 쓸 수 없다. 홈 화면 글자는 배경화면 밝기를 따르는 `ON_WALL`, `ON_WALL_MUTED`를 쓴다.
- 스타일이나 색상을 바꾸면 공유 스타일을 다시 만들고 LVGL 기본 테마(다크 여부 포함)를 다시 설정한 뒤, 화면 객체의 로컬 스타일에서 이전 역할 색과 같은 값을 새 값으로 한 번 바꾼다. 이 방식이 모호해지지 않도록 역할 색끼리, 또는 고정 색, 앱 아이콘 색과 같아지면 최하위 비트를 바꿔 구분한다. 상태 표시줄 아이콘, 위에서 끌어내리는 활동 패널, 2048과 메모리 게임도 스타일을 따른다. 갤러리, 리더, 건너기 게임 그림처럼 자체 색을 쓰는 부분은 원래 색을 유지한다.

## 라이브 배경화면의 부하
- 하나의 LVGL 타이머가 작은 객체만 움직인다. 별빛은 90ms마다 별 5개의 밝기를 바꾸고 몇 초마다 별똥별이 지나간다. 흐르는 빛은 70ms마다 큰 원 3개를 원 궤도로 2~4도씩, 물방울은 50ms마다 고리 14개를 2~4px 올리며 좌우로 흔든다.
- 홈 화면이 아니거나 화면이 꺼지면 타이머를 멈춘다. 라이브 배경을 고른 것 자체를 움직임 요청으로 보고, 설정의 애니메이션 끄기와는 연결하지 않는다.
- 흐르는 빛은 큰 반투명 원이 움직여 다시 그리는 면적이 가장 크다. 부하가 문제되면 별빛이나 물방울을 고른다.
