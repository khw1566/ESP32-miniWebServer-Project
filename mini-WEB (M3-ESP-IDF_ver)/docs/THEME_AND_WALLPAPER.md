# 테마와 홈 배경화면
설정 앱의 "테마" 카드에서 색상, 테두리, 모서리, 홈 배경화면을 바꾼다. 변경은 즉시 적용되고 마지막 변경 1.5초 뒤 NVS(`m3_device` 네임스페이스, `theme` 키, 12바이트)에 저장된다. 저장값이 없거나 손상되면 기본 테마(시안 `#00E5EF`, 마젠타 `#F548BA`, 테두리 없음, 둥근 모서리, 오로라 배경)를 쓴다.

## 설정 항목
- 기본 색상, 강조 색상: 견본 10색 또는 색상환 슬라이더. 슬라이더는 끄는 동안 미리보기만 바꾸고, 손을 뗄 때 전체 UI에 한 번 적용한다.
- 테두리: 없음, 은은하게(구분선 색 1px), 색상(기본 색상 1px, 60% 불투명도). 카드, 버튼, 목록 항목에 적용된다.
- 모서리: 둥글게, 보통, 각지게. 카드, 버튼, 목록, 입력칸, 세그먼트 버튼의 반경을 함께 바꾼다.
- 홈 배경화면: 정적 5종(오로라, 한밤, 노을, 바다, 흑백)과 라이브 3종(별빛, 흐르는 빛, 물방울).
- 기본 테마로 되돌리기.

## 구현
- `main/m3_theme.c`: 테마 값 검증, 기본값, NVS 읽기·쓰기.
- `main/m3_wallpaper.c`: LVGL 도형과 그라디언트로 배경을 그린다. 이미지 자산이 없어 Flash 증가는 코드와 문자열 정도다.
- `main/m3_theme_ui.inc`: 설정 카드, 공유 스타일 갱신, 색상 변경 적용. `m3_ui.c`가 포함한다.
- `CYAN`, `MAGENTA`, `ON_ACCENT`는 이제 런타임 변수다. 정적 테이블 초기값으로 쓸 수 없다.
- 색상 변경 시 공유 스타일과 LVGL 기본 테마를 다시 설정하고, 화면 객체의 로컬 스타일에서 이전 강조색과 같은 값을 새 값으로 한 번 바꾼다. 이 방식이 모호해지지 않도록 강조색이 중립색, 앱 아이콘 색, 서로와 같아지면 최하위 비트를 바꿔 구분한다.

## 라이브 배경화면의 부하
- 하나의 LVGL 타이머가 작은 객체만 움직인다. 별빛은 150ms마다 별 3개의 밝기, 흐르는 빛은 120ms마다 원 3개를 1px 안팎, 물방울은 70ms마다 고리 12개를 1~2px 이동한다.
- 홈 화면이 아니거나, 화면이 꺼졌거나, 설정의 애니메이션이 꺼져 있으면 타이머를 멈춘다.
- 흐르는 빛은 큰 반투명 원이 움직여 다시 그리는 면적이 가장 크다. 부하가 문제되면 별빛이나 물방울을 고른다.
