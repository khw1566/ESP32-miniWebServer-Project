# 상단 작업 패널

상단 44px 상태 바에서 아래로 70px 이상 끌고 놓으면 패널이 열린다.
패널은 손가락을 따라 움직이고, 놓으면 220ms 애니메이션으로 열린다.
패널 상단 손잡이에서 위로 50px 이상 끌거나 Close를 누르면 닫힌다.
앱 본문의 스크롤은 패널을 열지 않는다. 홈 이동도 패널을 닫는다.

작업 카드에는 현재 열린 앱, 오디오 재생, 음성 녹음/전송, Wi-Fi 설정
작업, 웹서버, Gemini 에이전트의 실제 공개 상태를 표시한다. ACTIVE는
해당 기능이 동작하거나 서비스가 활성화되었다는 뜻이다. CPU 점유율,
OS 전체 태스크 목록, 실제 HTTP 동시 요청 수를 의미하지 않는다.
표시 갱신 주기는 250ms이며 파일 저장공간은 서비스 작업에서 약 5초마다
읽는다. 패널을 열어도 라디오나 녹음·전송을 정지하지 않는다.

원형 그래프는 세 개다.

- RAM heap: 내부 할당 가능 heap의 전체 크기와 현재 남은 heap의 차이.
  칩의 모든 정적 RAM 영역을 측정하는 값은 아니다.
- PSRAM: 감지된 외부 PSRAM 전체에서 현재 free heap을 뺀 사용량.
- Flash files: SPIFFS 파일 저장공간의 사용량/용량. 16MiB Flash 중
  펌웨어, OTA, NVS 등 예약 영역은 파일 저장공간 분모에서 제외한다.
  SD 카드를 탐색해도 이 그래프는 SD 사용량으로 바뀌지 않는다.

상태 바의 Wi-Fi 품질은 텍스트 dBm 대신 네 개의 도형 막대로 나타낸다.
연결 상태 기준 RSSI 경계는 -55/-67/-75/-85dBm이다. 설정 AP는
자홍색, 연결된 STA는 시안색, 연결되지 않은 상태는 회색으로 구분한다.
상세 RSSI와 IP는 Wi-Fi 앱에서 확인할 수 있다. 배터리 측정값을
제공하는 하드웨어 인터페이스가 없어 임의의 배터리 수치를 표시하지 않는다.

호스트 검사: `node tools/test_activity_shade.cjs`.
실제 터치와 패널 성능은 업로드 후 보드에서 확인해야 한다.
