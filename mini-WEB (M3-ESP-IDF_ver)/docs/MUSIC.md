# SD·Flash 음악 앱

홈의 `음악 / Music` 앱은 라디오와 별도의 로컬 플레이어입니다.
SD `/media`와 하위 3단계 폴더, Flash 파일 저장소의 WAV/MP3/ADTS AAC를
이름순으로 최대 64곡 찾습니다. 한 페이지에 5곡, 이전/다음 목록과 곡 이동,
일시정지/재개·정지·목록 반복·진행률·재생 시간을 제공합니다.
홈으로 돌아와도 재생하며, 음악을 고르면 기존 오디오를 정지한 뒤 선택 곡을 재생합니다.
목록 갱신/SD·Flash 전환은 오디오를 정지한 상태에서 수행합니다.
마지막 곡까지 순차 재생하며, 목록 반복을 켜면 처음부터 이어집니다.

PCM16 WAV는 모노/스테레오 16–48kHz, MP3/AAC 디코더 PCM 출력은 모노/스테레오
8–48kHz를 처리합니다. 파일당 최대 256MiB이며, M4A 컨테이너·DRM 파일은 지원하지 않습니다.
웹 업로드의 기존 파일당 8MiB 제한과 Flash 파일명/저장공간 제한은 유지합니다.
큰 곡은 PC에서 SD카드의 `/media`에 복사하세요.

## PSRAM과 오디오

기존 단일 오디오 작업이 디코더·ES8311을 소유합니다. 새 음악 작업 스택을 만들지 않습니다.
목록은 PSRAM에 두고 파일은 64KiB PSRAM 읽기 버퍼를 사용합니다.
8MiB 이하 파일은 가능하면 전체를 PSRAM에 미리 읽습니다.
사전 읽기 할당 실패 또는 큰 파일은 파일 버퍼를 통해 순차 재생합니다.
전체 사전 읽기에 성공하면 포맷 파싱/디코더 준비 뒤 파일과 SD 잠금을 먼저 해제하여
PSRAM 캐시 재생 중 사진 위젯 등 다른 SD 사용을 허용합니다.
압축 입력 4KiB, PCM 32KiB, 모노 확장 64KiB도 PSRAM입니다.
파일 종료/정지/읽기·디코더·출력 오류 경로에서 파일/디코더/SD 잠금/버퍼를 해제합니다.
자동 다음 곡은 새 사용자 재생·정지 요청을 덮어쓰지 않습니다.

공통 음량 범위는 0–150입니다. 0–100은 ES8311 하드웨어 음량,
101–150은 하드웨어 100을 유지하고 PCM을 최대 1.5배 소프트웨어 증폭합니다.
16bit 범위에서 포화 처리하며 원본 디코더 버퍼를 변경하지 않습니다.
150은 전압 진폭 기준 약 +3.52dB이며 이미 큰 원본에는 클리핑이 생길 수 있습니다.
음악·라디오·TTS·유튜브·WAV·테스트음에 같은 출력 처리를 적용합니다.
기존 NVS 음량은 보존합니다.

## 검증과 Bluetooth

`node tools/test_music_player.cjs`는 실제 재생/증폭 C 본문을 호스트에서 실행하여
WAV/MP3/AAC 반복, 입력 분할·모노 확장, pause/resume, OOM·취소·읽기/쓰기 실패의
해제 경로, 증폭 포화와 자동 다음 곡의 취소 세대를 검사합니다.
MP3/AAC 디코더와 파일/I2S는 모의 객체입니다. 실제 디코딩·스피커 품질·SD 지연과
실기 안정성은 사용자 빌드 및 보드에서 확인해야 합니다.
PC 화면 시나리오는 음악 목록/재생/일시정지/150/Flash/목록 2페이지를 포함합니다.

사용자 선택에 따라 Bluetooth 이어폰 연결은 보류했습니다.
보드 C6는 [Bluetooth LE만 지원](https://docs.espressif.com/projects/esp-idf/en/stable/esp32c6/api-guides/ble/overview.html)하므로
일반 Classic A2DP 이어폰 송신 기능에는 별도 송신 하드웨어가 필요합니다.
