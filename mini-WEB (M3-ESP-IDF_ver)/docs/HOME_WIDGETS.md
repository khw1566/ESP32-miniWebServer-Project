# 홈 페이지와 위젯

홈 화면은 좌우 스와이프로 캘린더 → 메인 → 추가 앱 → 사진 위젯을 탐색합니다.
기본 진입과 앱에서 하단 바를 위로 밀어 복귀할 때는 메인 페이지입니다.
아래 페이지 표시를 눌러서도 이동할 수 있습니다. 페이지 이동은 LVGL tileview의
가로 스크롤/스냅을 쓰고 약 240ms로 전환합니다. 앱 내용의 세로 스크롤과
상단 작업 패널/하단 홈 제스처는 기존처럼 분리합니다.

메인 페이지에는 시계·날짜·Wi-Fi 상태 카드와 첫 6개 앱을 둡니다.
추가 앱은 페이지당 6개씩 자동으로 분배합니다. 기존 앱 ID와 기능은 보존합니다.
배경 원은 잘리는 전용 배경 레이어의 자식으로, 시계/카드/아이콘은 그 뒤에 생성하는
앞쪽 콘텐츠 레이어의 자식으로 고정했습니다. 배경이 위젯 위를 덮거나
레이아웃 공간을 밀어내는 것을 방지합니다.

캘린더는 한국 시간 기준 월간 달력입니다. 이전/다음 달, 오늘 복귀,
요일과 오늘 강조를 제공합니다. Wi-Fi 시간 동기화 전에는 안내를 표시합니다.
월을 직접 이동한 뒤에는 현재 달로 강제 복귀하지 않습니다.
일정 저장·공휴일 조회 기능은 포함하지 않습니다.

## SD 사진 준비

SD카드에 `widgets/photos` 폴더를 만들고 사진을 복사합니다.
카드는 부팅 전에 넣으세요. SD가 부팅 시 마운트되지 않았다면 다시 시작해야 합니다.
펌웨어 경로는 `/sdcard/widgets/photos`입니다. 위젯 첫 진입 시 폴더가 없으면
SD 관리 잠금 안에서 생성합니다. 하위 폴더는 탐색하지 않습니다.

- 지원: baseline JPG/JPEG, 비압축 24/32bit BMP. PNG/HEIC/애니메이션은 포함하지 않습니다.
- 파일당 최대 4MiB, 가로·세로 각각 2048 이하, 전체 최대 2,097,152 pixels.
  폰에서 옮길 때는 보통 480×800 또는 800×480 JPG로 줄이면 충분합니다.
  EXIF 자동 회전은 적용하지 않으므로 사진을 올바른 방향으로 저장하세요.
- 파일 이름순 최대 64장, 7초마다 다음 사진으로 넘어갑니다.
  한국어/일본어/한자 파일명은 기존 Unicode 글꼴을 사용합니다.
- 이전/다음·일시정지/재개·새로고침을 제공합니다.
  화면 비율을 유지하고 남는 부분은 검정 여백으로 채웁니다.
- 홈의 다른 페이지나 앱으로 이동하면 새 파일 읽기/자동 넘김을 중단합니다.
  다시 진입하면 폴더를 다시 읽습니다.

이미지 읽기/디코딩은 기존 서비스 작업에서 실행합니다. UI 작업은 완성된
RGB565 버퍼만 표시하며, 파일 접근이나 JPEG 디코더를 호출하지 않습니다.
JPEG 입력/출력과 432×480 이중 화면 버퍼(합계 829,440 bytes)는 PSRAM입니다.
동시에 표시 중인 버퍼는 디코더가 덮어쓰지 않습니다. 화면 버퍼는 페이지를
벗어나도 캐시로 유지하며, 임시 입력/디코딩 버퍼·JPEG 엔진은 매번 해제합니다.
JPEG 엔진 제어/DMA descriptor는 SDK 내부 메모리 요구사항을 따릅니다.
할당 실패·손상 파일·취소는 오류 상태로 처리하고 SD 잠금/임시 버퍼를 해제합니다.

SD가 업로드나 대용량 음악 스트리밍 중이면 현재 사진을 유지하고 다시 시도합니다.
8MiB 이하 음악의 PSRAM 사전 읽기가 성공하면 WAV 파싱/디코더 준비가 끝난 뒤
파일과 SD 잠금을 먼저 해제하므로 캐시 재생 중에는 사진을 읽을 수 있습니다.
파일 추가/삭제 후에는 사진 위젯의 새로고침을 누르세요.

## 확인 절차

컴파일 없는 호스트 검사:

```powershell
node .\tools\test_home_widgets.cjs
node .\tools\test_photo_worker.cjs
node .\tools\test_smartphone_home.cjs
node .\tools\test_touch_apps.cjs
node .\tools\test_i18n.cjs
node .\tools\test_music_player.cjs
```

검사는 실제 C 본문을 호스트 객체로 실행합니다. 달력 1970–2199년 전체 월,
BMP 방향/바이트 경계/화면 맞춤, 앞뒤 레이어 객체 트리, 페이지 선택,
표시 버퍼 보호, 사진 작업의 pause/간격/취소/OOM/파일 오류/SD 잠금 해제를 검사합니다.
SD와 JPEG 하드웨어는 모의 객체이므로 실기 디코딩의 증거가 아닙니다.

PC 시뮬레이터 소스에는 한국어/영어의 달력·다음 달·추가 앱·사진·일시정지·
빈 폴더·SD 사용 중 화면을 추가했습니다. 사진은 모의 RGB565 카드입니다.
프로젝트 지침에 따라 이번 작업에서 네이티브 PC/펌웨어 컴파일은 실행하지 않았습니다.
사용자가 PC 시뮬레이터를 빌드하려면 Visual Studio 도구가 설치된 PC에서 다음을 실행합니다.

```powershell
.\tools\ui_sim\build.ps1
```

ESP-IDF 터미널에서 `idf.py reconfigure build` 후 실제 SD 사진과 스와이프,
시계/카드/아이콘이 배경 위로 그려지는지, 상단 패널과 하단 홈 복귀,
음악/라디오와 동시 사용 및 할당 실패 로그를 확인하세요.
