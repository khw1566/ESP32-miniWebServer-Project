# JC4880P443C_I_W 케이스 제작용 제조사 자료

확인일: 2026-10-13. 대상은 4.3인치 JC4880P443C_I_W / JC-ESP32P4-M3
모듈이다. 별도 JC-ESP32P4-M3-DEV 개발 보드의 치수와 혼용하지 않는다.

제조사 공식 저장소의 PDF 원본을 이 폴더에 저장했다.

- [공식 PDF](https://github.com/guitionofficial/P4-series/blob/master/JC4880P443C_I_W/JC4880P443C_I_W/2-Specification/JC4880P443C_I_W%20Specifications-EN-V1.0.pdf)
- 로컬: `JC4880P443C_I_W-Specifications-EN-V1.0.pdf`
- 치수 도면: **6~7쪽**. `dimensions-page-6.png`, `dimensions-page-7.png`는
  원본 페이지를 렌더링한 것이며 치수 숫자를 수정하지 않았다.

| 도면의 대상 | 가로 × 세로 / 치수 | 근거 |
|---|---|---|
| 전면 유리 외곽 | 66.80 × 114.40 mm | 6쪽, 세로 방향 |
| 실제 표시 영역 | 56.16 × 93.60 mm | 6쪽 |
| 모듈 외형 | 69.41 × 117.01 mm | 7쪽 가로 도면을 세로 방향으로 환산 |
| 측면 전체 높이 | 13.8 mm | 7쪽 측면도 |
| 4개 체결 홀 | 직경 2 mm, `4*D2` | 7쪽 뒷면도 |
| 홀 중심 간격 | 긴 방향 108 mm × 짧은 방향 60 mm | 7쪽 뒷면도 |
| 뒷면/측면에 표시된 내부 구간 | 102.6 mm, 65.06 mm | 7쪽의 해당 치수선 확인 |
| 측면에 표시된 부분 높이 | 5 mm, 4.8 mm | 7쪽의 해당 치수선 확인 |

주의: 6쪽의 전면 유리와 7쪽의 모듈 외형은 서로 다른 치수다. PDF는
I_W와 케이스 포함 I_W_Y를 함께 다루므로, 13.8 mm를 모든 구입품의
동일한 부품 높이나 맨 PCB 두께로 해석하면 안 된다. 102.6/65.06 mm도
치수선 대상 확인 없이 전체 PCB 가로·세로라고 단정하지 않는다.

PDF에는 USB-C, SD 슬롯, 버튼, 마이크 음공, 스피커 커넥터의 정확한
절개 위치 좌표와 공차가 없다. 홀 중심, 전면 유리, 커넥터 돌출과 실제
부품 최고 높이를 소유 보드에서 실측한 뒤 최종 절개·스탠드오프를
정해야 한다. 그림 비율로 추정한 값을 확정 치수로 사용하지 않는다.

이 폴더의 `3_ESP32-P4.png`, `6_CODEC&TFCARD.png`, `7_OTHER.png`는
제조사 공식 회로도 원본으로, 마이크 및 커넥터 신호 확인용이다.
회로도는 기구 치수 도면을 대신하지 않는다. 다운로드 출처와 해시는
`sources.json`에 기록했다.
