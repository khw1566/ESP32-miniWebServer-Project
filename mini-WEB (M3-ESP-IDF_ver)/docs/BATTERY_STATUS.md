# M3 배터리 상태 표시와 하드웨어 확인

## 현재 확인한 사실

- 대상: GUITION JC4880P443C_I_W, JC-ESP32P4-M3.
- 제조사 사양서 3쪽은 리튬 배터리 인터페이스를 명시한다. 전원 회로도
  `hardware/1_PWR.png`에는 IP5306(U5), 배터리 CN4, USB5V_IN이 있다.
- IP5306 자체에는 배터리 잔량의 LED 표시 기능이 있다. 배터리 회로가
  없다는 의미가 아니다. 충전·승압 기능과 MCU가 읽을 수 있는 통신 연결은 구분한다.
- Injoinic I2C 레지스터 문서 2쪽은 일반 IP5306과 별도로 주문하는
  `IP5306_I2C`를 구분한다. I2C 주소 0xEA는 8비트 표기이며 ESP-IDF의
  7비트 주소는 0x75다. L1/L2가 SCL/SDA, L3가 IRQ로 쓰인다.
- 제조사 공개 전원 회로도(1_PWR)에서 U5의 LED1(2번), LED2(3번), LED3(4번)은
  연결되어 있지 않다. USB5V_IN도 MCU GPIO로 연결된 선이 없다.
- 2026-10-17 정정: `4_USB&IO` 회로도에 BAT+ -> R52 68k -> R55 0R -> GPIO53,
  R57 100k + C61 10nF -> GND 분압이 있다. GPIO53은 ESP32-P4 ADC2 채널 4다.
  이전 점검은 1_PWR만 보고 이 경로를 놓쳤다. 추가 배선 없이 배터리 전압을 읽을 수 있다.
- I2C 문서 7쪽의 0x70 bit3는 충전 활성, 0x71 bit3는 충전 완료 상태지만
  공개 회로도의 IP5306은 I2C가 MCU에 연결되지 않아 사용하지 않는다.

## 구현된 화면

- 상단 44px 바의 오른쪽에 벡터 플러그, 배터리 윤곽/채움, 퍼센트,
  충전 번개 표시를 추가했다. 시간·네트워크·오디오와 영역을 분리했다.
- 유선 감지 확인 시 플러그를 표시한다. 배터리가 없다고 확인되면 배터리와
  잔량을 숨긴다. 충전 상태가 판정된 경우에만 배터리에 번개를 표시한다.
- 배터리만 사용, 유선만 사용, 유선+충전, 유선+충전 종료, 20% 이하 저전력,
  감지 불가를 각각 처리한다. 감지 불가 값은 `--`다.

## GPIO53 배터리 전압 백엔드

`m3_power.c`는 ADC oneshot(12dB 감쇠, curve fitting 보정)으로 2초마다 16회
평균을 읽고 Vbat = Vpin x 168 / 100으로 환산한다. 서비스 작업에서만 읽는다.

| 판정 | 근거 | 신뢰도 |
| --- | --- | --- |
| 배터리 전압·잔량 | 10초 평균, EMA, 휴지 상태 Li-ion 곡선(3.30V 0% ~ 4.18V 100%) | 측정. 충전 중에는 높게 읽힘 |
| 배터리 미탑재 | 2.5V 미만, 4.4V 초과, 또는 20초 내 300mV 이상 요동 | 추정. 이 경우 외부 5V로 판정 |
| 외부 5V + 충전 | 1분 평균 6개가 연속으로 2mV 이상 상승(약 6분) | 추정. 연결 직후 약 6분 지연 |
| 배터리만 사용 | 1분 평균 6개 연속 하강 | 추정 |
| 분리 | 유선 판정 중 10초 평균이 80mV 이상 급락 | 추정 |
| 완충(유선 유지) | 유선 판정 중 6분간 변동 5mV 이하, 4.15V 이상 | 추정 |

부팅 직후 유선 여부는 알 수 없으므로 플러그를 숨기고 배터리와 잔량만 표시한다.
USB5V_IN이 MCU에 연결되지 않아 완충 상태로 USB에 꽂힌 경우처럼 전압 변화가
없는 상황은 유선으로 판정하지 못한다. 상태가 바뀌면 `M3_POWER` 로그에
`battery present ...mV ...% wired ... charging ...`가 출력된다.

## 보드에서 다음으로 확인할 내용

- 부팅 로그 `Battery ADC GPIO53 unit 2 ch 4`와 보정 여부.
- 배터리만 연결, USB만 연결, 배터리+USB, 충전 완료, 분리 순서로 `M3_POWER` 로그를 확인한다.
- 멀티미터로 BAT+ 전압을 재고 로그의 mV와 비교한다. 오차가 크면 분압 비율을 보정한다.
- IP5306의 무배터리 BAT 핀 동작은 실측으로 확인해 미탑재 임계값을 조정한다.

## 검증 범위

`node tools/test_power_status.cjs`는 실제 C 표시/상태 정규화 함수 본문을
호스트 모의 객체에서 실행해 경계값과 표시 조건을 검사하고, 실제 C 추정 함수
본문을 합성 전압 시계열(정지/미탑재/충전/분리/방전/부하 회복/완충)로 실행한다.
UI 시뮬레이터 시나리오는 84~89다. 네이티브 시뮬레이터 렌더링, 펌웨어 링크,
실물 배터리 감지는 실행하지 않았다. 프로젝트 규칙에 따라 빌드·플래시는
사용자가 실행한다.
