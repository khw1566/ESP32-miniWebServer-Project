# M3 기기 설정

설정 앱을 화면, 소리, 성능과 효과, 운영 모드, 언어, 음성 인식, 기기 정보로 분류했습니다.

| 분류 | 설정 | 범위와 동작 |
| --- | --- | --- |
| 화면 | 화면 밝기 | 5–100%, 기본 100% |
| 화면 | 화면 깨우기 | 기본 2초간 누르기, 또는 같은 곳을 빠르게 두 번 터치. 자동 저장 |
| 소리 | 음량·무음 | 0–150, 기본 40. 무음 해제 시 마지막으로 사용한 0보다 큰 음량으로 복귀 |
| 소리 | 버튼 효과음 | 끄기·부드럽게·벨·두 음. 기본 끄기. 선택 자동 저장과 미리 듣기 |
| 성능과 효과 | 최대 FPS | 5–60, 기본 30. LVGL 화면 다시 그리기 주기의 상한 |
| 성능과 효과 | 애니메이션 효과 | 화면 전환·스크롤 이동·막대 전환·대기 효과를 켜거나 끔 |
| 운영 모드 | 웹서버 집중 모드 | 기본 꺼짐. 적용 버튼으로 저장하고 재부팅 |
| 시스템 재시작 | 재시작 확인 | 취소 또는 지금 재시작. 진행 중 작업과 설정 저장 상태 확인 후 재부팅 |

화면·소리·효과는 변경 시 반영하고 서비스 작업에서 2초 간격으로 변경 내용을 저장합니다.
기존 음량은 이전 `m3_audio` 설정에서 가져오며, 새 설정은 NVS `m3_device/preferences`에
보관합니다. 운영 모드는 저장 성공 후에만 재부팅을 시작합니다. 저장 실패와 수동 재시작이
필요한 경우를 화면에 구분해 표시합니다.

밝기는 GPIO23에서 MP3202 EN 입력에 500 Hz PWM을 사용합니다. 제조사 데이터시트의
[EN 입력 PWM 조광 조건](https://www.monolithicpower.com/en/documentview/productdocument/index/version/2/document_type/Datasheet/lang/en/sku/MP3202/document_id/1495/)
에 맞춰 1 kHz 이하로 설정했습니다. PWM 초기화·제어 실패 시 기본 밝기를 유지합니다.
실제 밝기 범위·선형성·깜박임은 실물에서 확인해야 합니다.

최대 FPS는 패널의 물리적 스캔 주파수를 변경하지 않습니다. 제한값을 넘지 않도록
LVGL 재그리기 주기를 올림 계산합니다. 오디오, 게임 규칙, 영상 디코딩은 각자의
작업 주기로 유지합니다. 애니메이션을 꺼도 게임·영상 등 콘텐츠 자체의 동작은 유지합니다.

## 화면 끄기와 깨우기

상단 상태줄을 아래로 내려 상태 패널의 `화면 끄기`를 누릅니다. LCD 백라이트만 끄고
음악·라디오·서버·터치 처리는 유지합니다. 배터리 전원 차단이나 절전 부팅 모드가 아닙니다.
설정 앱의 화면 카드에서 깨우기 방식을 선택합니다.

- `2초간 누르기`: 화면 한 곳을 움직이지 않고 2초간 누릅니다.
- `두 번 터치`: 같은 곳을 빠르게 두 번 누르고 뗍니다. 각 터치는 250ms 이하,
  두 번의 뗌 사이 간격은 400ms 이하입니다. 드래그는 깨우기로 처리하지 않습니다.

화면이 꺼진 동안 앱 버튼은 터치를 받지 않습니다. 깨우는 손가락을 뗀 뒤 150ms 동안도
입력을 차단하여 뒤쪽 버튼이 함께 눌리지 않게 합니다. 켜질 때 현재 저장된 밝기로
복귀합니다. 터치가 초기화되지 않은 경우 화면 끄기를 거절합니다.
깨우기 선택은 기존 설정의 예약 바이트를 사용하므로 기존 밝기·음량 등의 값은 유지됩니다.

설정 앱의 `시스템 재시작`을 누른 뒤 `지금 재시작`으로 확인하면 설정을 저장하고
약 1.5초 후 재부팅합니다. `취소`는 재부팅하지 않습니다. 재생·녹음·AI·유튜브 저장이나
SD 변경 작업이 진행 중이면 거절하며, 설정 저장 또는 재시작 작업 생성 실패도 표시합니다.
이 재시작 버튼은 운영 모드 선택 스위치를 적용하지 않고 현재 저장된 운영 모드를 유지합니다.

## 상태 패널과 서비스 중지

원형 그래프는 내부 RAM, PSRAM, SD카드 사용량입니다. SD 용량은 파일 탐색 위치와
무관하게 서비스 작업에서 조회합니다. SD를 사용 중이면 마지막 정상 측정값에 `*`를
표시하며, 정상 측정 이력이 없으면 `SD 사용 중`으로 표시합니다. 카드가 없으면 `--`입니다.
용량은 약 5초마다 갱신하며 다른 작업이 길어지면 늦어질 수 있습니다.

CPU는 두 HP 코어의 FreeRTOS idle 실행 시간과 실제 경과 시간으로 약 2초 간격으로
계산합니다. 첫 측정 전이나 6초 이상 오래된 값은 `--`로 표시합니다. 현재 설정은 LP
프로그램을 사용하지 않으므로 `LP: 미사용`입니다. LP 프로그램을 활성화한 설정에서도
LP 부하를 HP 통계로 추정하지 않으며 `측정 미지원`으로 표시합니다.

음성입력·오디오·웹서버·AI 카드에는 중지 버튼이 있습니다. 음성입력과 AI는 취소를
요청하며 대화 기록은 유지합니다. 오디오는 대기 중 재생과 자동 다음 곡도 중지합니다.
녹음 중 오디오 중지를 누르면 녹음을 마치고 저장합니다. 취소와 저장은 작업이 정리될
때까지 진행 상태로 남을 수 있습니다. 오디오·음성 작업은 이후 다시 시작할 수 있습니다.
웹서버 카드의 중지는 아래의 전체 중지와 같습니다.

## 웹서버 배포 제어

펌웨어의 웹서버 앱에 다음 버튼을 추가했습니다. 설정과 파일, Wi-Fi 연결은 삭제하지 않습니다.

- `도메인 중지`: 외부 릴레이의 새 요청과 전송을 중단합니다. 로컬 IP·IPv6·.local HTTP는 유지합니다.
- `전체 중지`: 외부 릴레이와 로컬 HTTP를 중지합니다. SD 업로드·변경 작업이 사용 중이면
  작업을 마친 뒤 다시 시도하도록 안내합니다.
- `도메인 재개`: 로컬 HTTP가 실행 중일 때 외부 릴레이를 다시 사용합니다.
- `서버 시작`: 로컬 HTTP와 외부 릴레이를 다시 시작합니다.

시작·중지는 UI 작업에서 직접 HTTP를 종료하지 않고 서비스 작업에서 처리합니다.
Wi-Fi 재연결이나 설정 핫스팟 전환은 사용자가 중지한 서버를 자동으로 다시 시작하지 않습니다.
이 중지 상태는 현재 실행 동안 유지되며 재부팅하면 기본 시작 동작으로 돌아옵니다.
외부 서버의 진행 중 요청은 네트워크 타임아웃까지 남을 수 있고, 이미 브라우저에 받은
콘텐츠는 회수되지 않습니다. 릴레이 작업은 진행 중 통신을 정리한 뒤 TLS 메모리를 해제합니다.

## 버튼 효과음과 출력 잡음

소리 카드에서 효과음을 선택하면 짧은 미리 듣기를 요청합니다. 재생·녹음·음성입력 중,
무음 상태 또는 실제 재생 요청이 대기 중이면 효과음을 생략합니다. 효과음은 별도 대기
슬롯을 사용하고 오래된 요청은 버리며, 실제 재생 요청이 들어오면 양보합니다.
선택은 NVS `m3_device/click_sound`에 저장하여 기존 8바이트 설정을 보존합니다.

새 효과음은 48kHz 스테레오 PCM16이며 양 채널에 동일한 파형을 출력합니다. 시작과 끝의
음량을 완만하게 바꾸고 최대 진폭을 1800으로 제한합니다. 음량 100 초과의 추가 소프트웨어
증폭은 효과음에 적용하지 않습니다. 코덱 초기화와 샘플레이트 전환 중에는 앰프 GPIO11을
끄고, DAC 무음·DMA 무음 데이터·안정 대기 후 음량을 복구합니다. 종료 시에도 앰프를
먼저 끕니다. 마이크를 사용하는 동안은 앰프를 끈 상태로 유지합니다.

이 변경은 출력 전환의 팝 노이즈를 줄이기 위한 조치입니다. 실제 기기에서 들린 소리의
원인이나 제거 여부는 호스트 검사만으로 확정할 수 없습니다. 기본 효과음 끄기에서
앱 전환이 조용한지, 각 효과음의 음량과 음질, 무음 해제와 녹음 후 음악 복귀를 확인해야 합니다.

## 웹서버 집중 모드

1. 녹음·오디오·AI 작업과 SD 업로드를 마칩니다.
2. 설정 앱에서 웹서버 집중 모드를 켜고 `운영 모드 적용 및 재시작`을 누릅니다.
3. 저장에 성공하면 재부팅하고 화면·앰프를 끕니다. 디스플레이·터치·LVGL,
   오디오·녹음·AI·영상 작업을 초기화하지 않습니다. 사진·음악 목록·화면용 파일
   탐색도 서비스 작업에서 실행하지 않습니다.
4. Wi-Fi·설정 핫스팟·DNS/mDNS·시간 동기화·SD 파일·로컬 관리자·OTA·도메인 중계는
   유지합니다. AI 채팅·에이전트 처리 경로는 등록하지 않습니다. 관리자 인증에
   필요한 로그인 경로는 유지합니다.

재시작 대기 중에는 새 오디오 작업과 SD 변경 요청을 차단합니다. 기기 설정 변경으로
동적 디스플레이 버퍼와 선택 작업의 스택·힙 할당을 줄이지만, 펌웨어에 정적으로
예약된 BSS나 코드 공간을 다른 용도로 재배치하지는 않습니다. 메모리 절감량이나
처리량 증가는 사용자 빌드의 링크 맵과 같은 조건의 실기 로그로 확인해야 합니다.

## 일반 모드로 복귀

- 같은 Wi-Fi의 `http://보드IP/device-settings`에서 관리자 비밀번호를 입력하고
  현재 설정을 불러옵니다. 집중 모드를 끄고 저장하면 일반 모드로 재부팅합니다.
  관리자 화면의 설정 탭에도 기기 설정 링크가 있습니다.
- 네트워크 주소를 모르거나 웹 설정을 사용할 수 없으면 BOOT를 누른 채 재시작합니다.
  그 부팅에서는 집중 모드를 무시하고 화면과 설정 핫스팟을 시작합니다. 저장된 집중
  모드 선택은 삭제하지 않으므로, 설정 앱에서 끄고 적용해야 이후 부팅도 일반 모드가 됩니다.

로컬 웹 설정은 관리자 비밀번호를 매 요청에서 확인합니다. 설정 값은 서버에서
범위와 자료형을 검증하며, 응답에 비밀번호를 포함하지 않습니다. 공개 도메인 중계로
이 관리자 설정 페이지를 제공하지 않습니다.

## 검증

`node tools/test_preferences.cjs`와 `node tools/test_device_settings.cjs`는 실제 C 함수의
제어 흐름을 NVS·SD·마이크·HTTP 모의 환경에서 실행합니다. 값 검증, 무음 복귀,
FPS 상한, 저장 실패 후 재시도, BOOT 예외, 녹음·업로드 중 모드 변경 차단,
관리자 인증과 복귀 경로를 검사합니다. 타깃 C 컴파일이나 하드웨어 검증은 아닙니다.

PC 미리보기에는 `73_settings_display`부터 `77_settings_no_effects`까지 추가했습니다.
`node tools/test_screen_wake.cjs`는 실제 C 깨우기 정책과 UI·백라이트 제어 흐름을
모의 환경에서 검사합니다. 짧은 터치·느린 터치·드래그 거절, 타이머 순환,
깨우기 손가락의 입력 차단, 밝기 복귀와 실패 경로, 재시작 확인·취소를 포함합니다.
새 PC 시나리오 `82_settings_double_tap`부터 `87_hold_wake`까지는 깨우기 설정,
재시작 확인, 상태 패널의 화면 끄기와 터치 복귀를 다룹니다.
`node tools/test_service_controls.cjs`는 배포 중지·재개, 업로드 사용 중 거절, 중복 요청,
Wi-Fi 자동 재시작 억제와 작업 취소를 검사합니다. `node tools/test_button_sounds.cjs`는
실제 C 효과음의 진폭·평균·시작과 끝, 코덱·앰프 순서와 실패 경로, 재생 우선권을 검사합니다.
PC 시나리오 `88_settings_sounds`부터 `92_status_no_sd`는 새 설정·웹 제어·상태 패널을 다룹니다.
프로젝트 규칙에 따라 새 네이티브 빌드와 한국어·영어 화면 렌더링은 사용자 실행이
필요합니다. M3 프로젝트에서 `idf.py build` 후 업로드하고 밝기·무음·FPS·효과 전환,
재부팅 후 설정 유지, 집중 모드의 힙·작업 목록·SD/OTA/중계, 웹·BOOT 복귀를 확인하세요.
