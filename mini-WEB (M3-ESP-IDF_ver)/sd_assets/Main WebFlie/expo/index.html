지금 보고 있는 이 화면은 손바닥만 한 보드 한 장이 보내고 있습니다.

PC도, 클라우드도 거치지 않습니다. ESP32-P4 보드가 직접 웹 서버가 되어 페이지를 만들고 보냅니다.

두뇌는 ESP32-P4입니다.

400 MHz RISC-V 코어 두 개와 32 MB PSRAM. 웹 요청 처리와 4.3인치 터치 화면, 스피커 소리를 이 칩 하나가 함께 맡습니다.

무선 연결은 옆의 ESP32-C6가 맡습니다.

Wi-Fi 6로 공유기에 연결됩니다. 공유기가 없는 곳에서는 보드가 스스로 Mini-WebServer-M3-Setup Wi-Fi를 열어 휴대폰이 바로 접속할 수 있습니다.

웹 페이지는 SD 카드에서 꺼내 옵니다.

SD 카드의 Main WebFlie 폴더에 HTML 파일을 넣어 두면, 부팅할 때 PSRAM으로 미리 읽어 두었다가 요청이 오는 즉시 보냅니다. 지금 이 전시 페이지도 그렇게 동작합니다.

요청 하나가 거쳐 가는 길

  1. 휴대폰 브라우저가 페이지를 요청합니다.
  2. C6가 Wi-Fi로 받아 P4에 넘깁니다.
  3. P4가 PSRAM에 올려 둔 파일을 찾아 응답합니다.
  4. 응답이 다시 C6를 거쳐 휴대폰 화면에 그려집니다.
