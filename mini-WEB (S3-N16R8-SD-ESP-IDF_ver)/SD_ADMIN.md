# 관리자 웹 SD카드 관리

변경된 펌웨어를 사용자가 빌드·설치한 뒤 보드의 로컬 `/admin`에 로그인하고 **파일** 탭을 엽니다. 상단 SD카드 카드에서 전체·사용·남은 용량과 사용률 그래프를 확인합니다.

- 폴더의 **열기** 및 **상위 폴더**로 탐색합니다. 목록은 RAM 사용량을 제한하기 위해 3개씩 표시합니다.
- **파일 넣기**로 현재 폴더에 여러 파일을 순서대로 업로드합니다. 파일당 1바이트~8 MiB를 지원합니다. 같은 이름은 거부하므로 이름을 바꾸거나 기존 파일을 먼저 삭제합니다.
- 파일별 **다운로드**로 PC에 가져오고 **삭제**로 SD에서 지웁니다. 삭제 전 확인 창을 표시합니다. 폴더 삭제는 지원하지 않습니다.
- `index.html`을 SD 루트에 넣으면 기본 웹페이지로 제공됩니다. 미디어를 `media` 폴더에 넣으면 `/media/파일명`으로 제공됩니다. 외부 미디어 제공에는 기존 ASCII 파일명·확장자 제한이 적용됩니다.
- SD 미인식 및 저장소 사용 중은 오류 메시지로 표시합니다. 카드를 전원 없이 분리하고 다시 부팅한 뒤 **새로고침**으로 확인합니다.

API는 로컬 `/api/sd/files`의 GET(목록·다운로드), POST(업로드), DELETE(파일 삭제)입니다. 모든 작업은 관리자 인증을 확인하며, 비밀번호는 URL에 넣지 않습니다. 공개 중계 주소에서는 관리자 API에 접근할 수 없습니다. 임시 파일에 1 KiB씩 기록하고 저장 완료 후 게시하며 전송 실패 시 부분 파일을 제거합니다. 재부팅 시 남은 임시 파일도 정리합니다. 클라우드 업로드와 SD 관리 작업은 같은 잠금으로 조정합니다.

구현은 `main/web_sd_admin.inc`, 화면은 `main/web_sd_admin_ui.inc`로 분리했습니다. `node tools/test_sd_admin.cjs`로 목록 페이지, 용량 그래프, 인증된 삭제, 미인식 오류, 큰 파일 거부 및 UI 복구를 확인했습니다. 전체 관리자 페이지의 JavaScript 문법도 확인했습니다. 프로젝트 지침에 따라 펌웨어 컴파일·업로드 및 실제 카드 전송은 수행하지 않았습니다.
