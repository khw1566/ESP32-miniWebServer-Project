# M4 음악 앱

메인 화면에 현재 곡의 파일명, 원형 음량 그래프, 재생 시간과 진행률을 표시한다.
긴 파일명은 가로로 순환 표시한다. 파일의 ID3 앨범·아티스트 정보는 읽지 않는다.

- 원형 그래프 영역을 왼쪽으로 스와이프하면 다음 곡, 오른쪽이면 이전 곡을 재생한다.
  위아래 드래그는 페이지 스크롤에 사용한다. 하단 홈 제스처는 유지한다.
- 재생 버튼은 선택 곡을 시작한다. 재생 중에는 일시정지와 재개를 전환한다.
- 곡 목록 버튼은 SD `/media` 또는 Flash의 목록을 연다. 최대 64곡이며 5곡씩 표시한다.
  선택 곡과 자동 전환된 곡의 페이지를 따라간다.
- 반복 끔은 목록 끝에서 정지한다. 전체 반복은 처음으로 돌아간다.
  한 곡 반복은 자연스럽게 재생이 끝났을 때 같은 곡을 다시 재생한다.
  사용자의 이전·다음·스와이프 조작은 한 곡 반복보다 우선한다.
- 랜덤 재생은 아직 재생하지 않은 곡을 선택한다. 반복 끔에서는 한 차례 재생 후 정지하고,
  전체 반복에서는 새 순서를 시작한다. 같은 곡을 연속으로 선택하지 않는다.
  한 곡 반복이 켜져 있으면 그 설정이 우선한다. 직접 곡을 선택하면 새 순서를 시작한다.
  이전 버튼은 재생 이력 대신 다른 곡을 랜덤 선택한다.
- 이퀄라이저는 저음·중음·고음을 각각 -12~+12 dB로 조절한다.
  기본 음색 버튼은 세 대역을 모두 0 dB로 되돌린다. 설정은 실행 중에 유지한다.

그래프는 임의 애니메이션이 아니라 디코딩한 PCM을 분석한다. 약 200 Hz와 4 kHz의
상보적인 1차 필터로 세 대역을 나누고 평균 절대 진폭을 계산한다. 24개 방사형 선은
세 대역을 각각 8개씩 나타낸다. 화면 갱신 간격은 40 ms이며 부드럽게 보간한다.
일시정지·정지 시 선이 기본 반지름으로 줄어든다. 출력 하드웨어의 음량 감쇠 전 신호다.
0 dB 설정은 원래 PCM을 그대로 출력한다. 증폭된 신호는 PCM16 범위에서 포화 처리한다.

## 검증

`tools/test_music_player.cjs`와 `tools/test_music_features.cjs`는 실제 C 함수 본문을
호스트 모의 환경에서 실행한다. 자동 전환·반복·랜덤·스와이프 방향, 모노/스테레오,
대역 응답·포화·필터 상태 연속성·취소·읽기/출력 오류·할당 실패 후 해제를 검사한다.
`test_audio_output.cjs`, `test_touch_apps.cjs`, `test_i18n.cjs`, `test_japanese.cjs`도 실행한다.

현재 설치 기준은 ESP-IDF 5.5.5, LVGL 9.2.2, ESP32-P4다. 호스트 검사는 컴파일·링크나
실기 검증을 대신하지 않는다. 프로젝트 지침에 따라 펌웨어와 PC 시뮬레이터의 컴파일은
사용자가 수행한다. 시뮬레이터에는 랜덤/한 곡 반복 및 EQ 화면 시나리오를 추가했다.
새 한국어·영어 PNG의 글자 잘림과 스크롤, 실기의 스와이프·음질·장시간 재생을 확인해야 한다.

ESP-IDF 환경에서 프로젝트 폴더의 `idf.py build`를 실행한다. 업로드 후 SD와 Flash의
WAV/MP3/AAC에서 이전·다음, 목록 페이지, 반복 세 모드, 랜덤, EQ, 음량 150,
일시정지 중 곡 전환과 앱 이동을 확인한다.
