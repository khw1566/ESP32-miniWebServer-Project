# 홈·작업 패널·라디오 개선

홈의 달력·메인·추가 앱·사진 페이지는 투명 타일 아래 공통 배경 하나를 쓴다.
좌우 스와이프 중에도 배경은 고정되어 이어진다. 메인은 기존 주요 앱 6개,
추가 화면은 나머지 9개를 3×3으로 배치한다. 추가 화면의 제목·안내 문구와
하단 페이지 이름을 없앴으며 페이지 점과 앱 이름은 유지한다.

상단 패널은 기존 RAM·PSRAM·Flash 원형 그래프 아래 HP0·HP1 사용률의
0~100% 그래프(최근 60개 표본)를 표시한다. 실행 앱·오디오·음성입력·Wi-Fi·
웹서버·AI 상태에는 기존 LVGL 아이콘 글꼴의 아이콘과 활성 색상을 붙인다.
사용률은 각 코어에서 IPC로 읽은 유휴 작업의 누적 실행 시간 차이로 계산한다.
초기 표본 전이나 실행 시간 통계가 꺼져 있으면 `--`로 표시한다. 서비스 작업이
통상 약 1초마다 수집하며 Wi-Fi 연결 등 긴 작업 중에는 간격이 늘어날 수 있다.
LP 코어는 이 FreeRTOS 작업 집계 대상이 아니므로 가상의 LP 사용률을 만들지 않는다.

공개 Wi-Fi를 누르면 비밀번호 없이 DHCP로 연결 요청을 즉시 큐에 넣는다.
기존 비밀번호와 고정 IP를 재사용하지 않는다. 보안 네트워크는 비밀번호
입력으로 이동하며 기존 저장·실패 시 설정 AP 복구·재시도 정책을 유지한다.
공개망의 웹 로그인 페이지 인증은 별도이며 Wi-Fi 연결 요청과 구분된다.

## 라디오

기존 10개를 유지하고 아래 10개를 추가해 총 20개(한국 6, 일본 7, 세계 7)다.

- 한국: KBS 1라디오, Happy FM, 3라디오, **클래식FM**, Cool FM.
- 일본: J1 HITS, J1 GOLD, Shonan Beach FM, asia DREAM Japan Hits, Jazz Sakura.
- 기존 Radio Swiss Classic도 유지한다.

국가 탭은 방송 콘텐츠 기준이다. J1과 asia DREAM은 해외에서 송출하는 일본 음악 채널이다.

방송사 출처와 공개 주소는 저장소 루트의 `tube-relay/radio_stations.json`에
관리한다. KBS는 공식 API에서 유효기간이 짧은 HLS 주소를 매번 새로 얻는다.
서명된 스트림 주소를 저장하거나 로그에 출력하지 않는다. 스트림이 변경되면
목록을 갱신하고 `python -X utf8 tools/generate_radio_catalog.py`로 보드 목록을 생성한다.

라디오의 **연결 및 음질**에서 선택하고 재생 버튼을 다시 누른다.

| 선택 | 전송 형식 | 시간당 오디오 전송량(헤더 제외) |
| --- | --- | --- |
| 직접 | 기존 방송의 MP3/AAC | 원본 음질에 따름 |
| 절약 | MP3 32 kbps, 22.05 kHz, 모노 | 약 14.4 MB |
| 표준 | MP3 64 kbps, 32 kHz, 모노 | 약 28.8 MB |
| 고음질 | MP3 128 kbps, 44.1 kHz, 스테레오 | 약 57.6 MB |

중계 선택 시 기존 YouTube PC 중계서버가 음성만 재인코딩한다. 영상이나
PCM을 보드로 전송하지 않는다. 절약은 128 kbps 원본 대비 오디오 전송량을
75% 줄인다. 음질 손실과 교환하는 옵션이며 실제 끊김은 회선 상태에도 달려 있다.
HLS인 KBS는 PC 중계 필수이며 ‘직접’ 선택 시 표준 중계로 재생한다.
사용자 입력 URL은 직접 재생만 지원한다. 임의 URL을 중계서버로 보내지 않는다.

`/api/radio?station=<목록 ID>&profile=economy|balanced|high`는 기존 중계
인증을 사용한다. 한 번에 FFmpeg 하나를 허용하며 연결 해제 시 종료한다.
Node 스트림 backpressure로 느린 클라이언트의 무제한 버퍼 증가를 막는다.
보드는 중계 주소에만 인증 헤더를 붙이고 중계 응답의 외부 리디렉션을 거부한다.
기존 PSRAM 압축·PCM 링, 전송량에 맞춘 프리버퍼, 취소·TLS 해제 경로를 유지한다.

## 검증 및 적용

호스트 검사는 `test_home_panel.cjs`, `test_home_widgets.cjs`, `test_photo_worker.cjs`,
`test_touch_apps.cjs`, `test_radio_buffer.cjs`, `test_i18n.cjs`를 사용한다.
PC 중계는 `node test_radio.mjs`로 실제 FFmpeg의 출력 코덱·샘플레이트·채널·
압축률·동시 연결 제한·종료를 합성 오디오에서 검사한다.
`node verify-radio.mjs --live`는 새 방송 10개에서 2초 분량의 인코딩을 검사하고
서명이나 인증 정보 없이 `cache/radio-verification.json`에 결과를 기록한다.
이는 실물 보드의 오디오 출력·스와이프·Wi-Fi 연결·장시간 버퍼링 검증이 아니다.
`node verify-radio.mjs --live --relay`는 로컬 PC와 공개 터널에서 기존 인증으로
KBS 클래식FM의 절약 모드 MP3를 수신하고 연결을 종료한다. 인증 값은 출력하지 않는다.

PC 중계프로그램을 재시작해 새 라디오 API를 적용한다. 보드는 프로젝트 지침에
따라 사용자가 빌드·플래시한다. 네이티브 UI 컴파일·렌더링은 실행하지 않았다.

```powershell
.\m4.ps1 -Action Build
.\m4.ps1 -Action Flash -Port COM8
```

`COM8`은 예시다. 적용 후 한국어·영어 화면, 3×3 아이콘 잘림, 배경 스와이프,
작업 패널 그래프·스크롤 문구, 공개 Wi-Fi 연결, KBS·일본 채널별 재생 및
각 음질에서 정지·전환·장시간 재생을 확인한다.
