# 큰 글자·순환 텍스트·일본어

큰 제목용 한글 글꼴의 대체 글꼴이 영문 Montserrat로 바로 연결되어 있어,
제목에 미리 포함되지 않은 한글과 일본어를 표시하지 못했습니다.
또한 22px TTF 줄 높이는 반굵기/안티앨리어싱으로 커진 실제 글리프보다 작았습니다.
제목 줄 높이를 실제 비트맵 경계 기준 30px, 기준선을 7px로 바꾸고,
제목 → 공통 22px 확대 글꼴 → Montserrat 20의 경로로 연결했습니다.
확대 글꼴은 기존 Nanum 한글과 CJK 1bpp 비트맵을 그대로 사용하여 현재 한 글자를
LVGL A8 draw buffer에 확대합니다. 큰 일본어/한자 전용 비트맵 전체를 추가하지 않습니다.
라이브 표시도 CJK를 지원하는 글꼴을 사용합니다.

파일명, 앱 제목, 음악/라디오 제목, 사진 이름, 영상 제목/채널/메타데이터,
홈 상태와 작업 패널의 고정 영역을 말줄임표에서 순환 스크롤로 바꿨습니다.
버튼 문구도 버튼의 내용 폭을 제한하여 길 때 순환합니다.
영역에 들어가는 짧은 문구는 정지하며, 넘치는 경우에만 LVGL이 애니메이션을 만듭니다.
설명 문단은 줄바꿈하고 앱을 세로로 스크롤하여 읽습니다.
주기적 상태 갱신 때 같은 파일명을 다시 설정하지 않아 진행 중인 순환 표시를 유지합니다.
상태 번역 버퍼는 PSRAM에 두며 UTF-8 문자 중간에서 자르지 않습니다.

## 일본어 사용

설정 → 언어 → `日本語`를 선택합니다. 한국어/English/日本語를 재부팅 없이
바꾸며 선택은 기존 `m4_ui/lang` NVS에 저장합니다. 기존 한국어=0, 영어=1 값은 유지합니다.
일본어 메뉴 242개, 서비스 상태 접두어 204개와 내부 표시 토큰 3개를 포함합니다.
날짜·달력 요일·조회수도 일본어로 표시합니다. 시간대는 기존 UTC+9입니다.

가상키보드의 `かな`를 누르면 히라가나, `カナ`를 누르면 가타카나로 입력합니다.
`゛`는 탁점, `゜`는 반탁점, `小`는 작은 글자 전환입니다.
이 키들은 입력 끝의 글자에 적용합니다. 예: か→が, は→ぱ, つ→っ, ア→ァ.
ABC/한 키로 기존 영문/한글 입력으로 돌아갑니다.
일본어 UI에서 자연어 입력창은 히라가나로 열리며, 숫자·IP 키패드는 유지합니다.
한자 표시를 지원하지만 가나→한자 변환 사전/IME는 포함하지 않습니다.
음성 앱의 STT/TTS 기본 언어는 기존 한국어입니다.

일본어 번역의 원본은 `translations/ja.json`, 생성 파일은 `main/m4_i18n_ja.inc`입니다.
문구를 추가할 때 다음 도구가 누락된 번역과 printf 서식 불일치를 검사합니다.

```powershell
python .\tools\generate_japanese.py
python .\tools\generate_ui_fonts.py
node .\tools\test_japanese.cjs
node .\tools\test_i18n.cjs
node .\tools\test_touch_apps.cjs
python .\tools\preview_large_fonts.py
```

호스트 검사는 실제 C 본문을 모의 객체로 실행합니다. 모든 한글/추가 CJK의 큰 글자
영역 경계, 확대 픽셀, 가나 변환/UTF-8 편집, 번역 누락/서식/글리프,
언어 선택·복원, UTF-8 상태 버퍼를 1–256 bytes로 잘랐을 때의 유효성을 검사합니다.
`large_font_preview.png`는 생성된 글리프 데이터 확인용이며 PC UI나 보드 캡처가 아닙니다.
프로젝트 규칙에 따라 네이티브 PC/펌웨어 컴파일은 실행하지 않았습니다.
PC 시뮬레이터 소스에는 일본어 설정/홈/달력/파일/음악 순환 표시 시나리오를 추가했습니다.
실제 LCD의 큰 글자와 순환 표시 및 OTA 4MiB 슬롯 여유는 사용자 빌드로 확인하세요.

```powershell
idf.py reconfigure build
```
