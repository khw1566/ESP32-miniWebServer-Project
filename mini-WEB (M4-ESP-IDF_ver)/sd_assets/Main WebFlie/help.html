WELCOME GUIDE

Mini WebServer 안내 가이드

마이크로컨트롤러 단일 칩 기반 초경량 독립형 웹서버에 오신 것을 환영합니다.

핵심 사용 방법 안내
1
관리자 대시보드 접속
관리자 화면(`/admin`) 접속 시 비밀번호(기본값 00000000)를 입력하여 로그인합니다. 접속 후 원하시는 비밀번호로 언제든 변경할 수 있습니다.
2
웹 콘텐츠 업로드 & 관리
관리자 대시보드의 드래그 앤 드롭 영역에 HTML, CSS, JS, WebP 파일을 업로드하면 즉시 마이크로컨트롤러 내부 플래시(SPIFFS)에 보관 및 서빙됩니다. 설정에서 업로드한 HTML 경로를 지정하면 주소 루트의 첫 화면으로 표시할 수 있습니다.
3
AI 웹 생성 어시스턴트 활용
웹 개발 지식이 없어도 상단의 [AI 웹 생성기]를 통해 원하는 페이지를 말로 설명하면 즉시 탑재 가능한 단일 HTML 파일을 생성 및 미리보고 다운로드할 수 있습니다.
4
첫 접속 화면 출력 설정
관리자 대시보드의 환경설정에서 기본 화면을 선택하거나 업로드한 HTML 경로(예: /welcome.html)를 지정할 수 있습니다. 이 설정은 보드의 IPv4 및 IPv6 주소로 접속할 때 적용됩니다.
기본 관리자 비밀번호: 00000000 | LAN 연결 안내: /setup | AI 생성기: /ai
