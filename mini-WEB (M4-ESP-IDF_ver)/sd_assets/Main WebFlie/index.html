01 / DISPLAY

터치 대시보드

MIPI-DSI 화면과 PSRAM 이중버퍼를 사용합니다. 접속 주소 QR, 메모리 그래프, 저장소와 오디오 상태를 화면에서 확인하세요.

02 / WIRELESS

SoftAP로 시작

C6를 통한 Wi-Fi 연결. 브라우저 설정에서 공유기 접속 정보와 DHCP·고정 서버 IP, 게이트웨이, DNS를 저장합니다.

03 / AUDIO + FILES

파일과 소리

SD 파일을 웹 관리자로 관리합니다. SD /media에 저장한 PCM16 WAV 파일은 터치 화면에서 스피커로 재생할 수 있습니다.

YOUR FIRST CONNECTION

연결은 간단하게.

인터넷 없이도 보드의 웹 페이지와 로컬 관리자에 접속할 수 있습니다. 클라우드 중계와 AI 기능은 별도 서비스 설정이 필요합니다.

네트워크 설정
  1. 첫 부팅 후 Mini-WebServer-M4-Setup Wi-Fi에 연결하세요.
  2. http://192.168.4.1/setup에서 공유기와 서버 IP를 설정하세요.
  3. 설정 저장 후 재부팅됩니다. 같은 공유기에 접속해 화면의 주소 또는 QR을 여세요.
  4. 연결 설정을 복구하려면 BOOT를 누른 상태로 전원을 켜세요. 저장된 설정은 보존됩니다.
