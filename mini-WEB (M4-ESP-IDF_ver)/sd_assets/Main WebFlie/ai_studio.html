Google Gemini API 키 무료 발급

1
구글 AI 스튜디오(aistudio.google.com)에 구글 계정으로 로그인합니다.
2
'Create API key' 파란색 버튼을 클릭하여 새 키를 생성합니다.
3
생성된 키 문자열(AIzaSy...)을 복사하여 좌측 설정의 Gemini API 키 란에 붙여넣습니다.
4
키를 붙여넣고 키 저장·교체를 누르세요. 이후 보드가 저장된 키로 Google에 HTTPS 요청합니다. 보드에 인터넷 연결이 필요하며, Google Cloud에서 키의 API 제한과 사용량 제한을 설정하세요.
