# P4 계열 SD 전용 관리자 파일 관리

M4와 별도 P4 펌웨어에 적용합니다. 다른 보드의 플래시 저장 정책은 변경하지 않습니다.
관리자 로그인 후 **파일** 탭에서 SD카드를 관리합니다.

- 파일 선택 또는 끌어 놓기로 현재 폴더에 여러 파일을 저장합니다. 파일당 0~8 MiB입니다.
- 같은 이름이 있으면 교체 여부를 확인합니다. 기존 파일을 먼저 삭제할 필요가 없습니다.
- **새 텍스트 파일**로 파일을 만들거나 각 텍스트 파일의 **편집** 버튼을 누릅니다.
  UTF-8 텍스트를 256 KiB까지 편집하며 빈 파일도 저장합니다. Ctrl/Cmd+S로 저장하고
  Escape로 닫습니다. 저장되지 않은 변경을 닫을 때는 확인합니다.
- **다운로드**, **삭제**, 선택 파일 일괄 다운로드·삭제, 하위 폴더 탐색을 지원합니다.
- SD 미인식·용량 부족·다른 작업의 잠금·전송 오류를 표시합니다. 편집 저장에
  실패하면 입력한 내용은 편집기에 남습니다.

## 저장과 복구

수정은 GET으로 받은 ETag를 PUT의 If-Match로 전달합니다. 파일 내용이 그 사이에
바뀌면 412 응답으로 거부합니다. 새 파일 POST는 같은 이름을 덮어쓰지 않습니다.
다운로드·읽기·추가·수정·삭제 API는 관리자 비밀번호 또는 관리자 세션 인증을 요구합니다.
숨김 폴더, `.private` 및 경로 이탈은 허용하지 않습니다.

새 내용은 SD의 숨김 임시 파일에 쓰고 flush/fsync/close를 확인한 뒤 적용합니다.
교체할 원본은 같은 폴더의 `.<파일명>.sd-bak`에 잠시 보관합니다. 적용 실패 시
원본으로 되돌리며 되돌리기도 실패하면 백업을 보존합니다. 재부팅 때 루트의
백업을 확인하고, 관리자에서 폴더를 조회하거나 해당 파일을 열 때도 복구합니다.
새 파일과 백업이 함께 있으면 적용된 새 파일을 유지합니다. FAT 파일시스템의
모든 전원 차단 상황에 대한 무손실 보장은 아니므로 중요한 SD카드는 별도 백업합니다.

현재 FAT 긴 이름 설정은 128이며 안전한 교체용 백업 이름을 위해 원래 파일명은
120 UTF-8 바이트 이하여야 합니다. 이를 초과하는 파일은 다운로드할 수 있지만
교체는 오류로 거부합니다. 내용 교체는 기존 파일과 새 파일 모두 8 MiB 이하입니다.
임시 파일을 위한 여유 공간도 필요합니다.

M4의 `Main WebFlie` 폴더는 기존 부팅 PSRAM 웹 캐시를 유지합니다. 이 폴더의
수정·업로드·삭제는 SD에 저장되며 웹 캐시 반영에는 재부팅이 필요합니다.
일반 SD 루트의 웹 파일과 `media` 파일은 파일시스템에서 제공합니다.

## 플래시 사용 범위

P4/M4는 사용자 파일용 SPIFFS를 마운트·포맷하지 않습니다. 플래시 파일 관리
영역은 표시하지 않으며 이전 플래시 파일 API는 410을 반환합니다. SD가 없어도
내장 관리자·Wi-Fi 설정 화면은 사용할 수 있고 파일 저장은 실패 상태로 표시합니다.
AI 파일 도구도 SD를 사용합니다. M4의 플래시 파일 탐색·음악 파일 접근도 차단합니다.

펌웨어·OTA·NVS 설정은 계속 플래시에 있습니다. 기존 파티션 표나 플래시 데이터는
지우지 않으며 이전 플래시 파일을 SD로 자동 복사하지 않습니다. 기존 파일이
필요하면 이전 펌웨어에서 먼저 다운로드해 SD에 보관하세요. 관리자 기본값 복원은
설정만 초기화하며 SD 파일과 SD의 개인 키 파일은 삭제하지 않습니다.

## 검증

저장소 루트에서 실행한 호스트 검사:

```powershell
node tools/test_p4_sd_editor.cjs
node "mini-WEB (M4-ESP-IDF_ver)/tools/test_sd_admin.cjs"
node "mini-WEB (P4-ESP-IDF_ver)/tools/test_sd_admin.cjs"
node "mini-WEB (M4-ESP-IDF_ver)/tools/test_dashboard_polling.cjs"
node "mini-WEB (P4-ESP-IDF_ver)/tools/test_dashboard_polling.cjs"
node "mini-WEB (M4-ESP-IDF_ver)/tools/test_web_gzip.cjs"
node "mini-WEB (M4-ESP-IDF_ver)/tools/test_music_player.cjs"
node tools/test_file_manager.cjs
```

JavaScript DOM/통신 모의 검사와 실제 C 교체·복구 함수 본문의 파일시스템 모의
검사입니다. 컴파일·링크·실제 브라우저 렌더링·실제 SD 전송의 증거는 아닙니다.
M4 압축 웹 자원은 `tools/generate_web_gzip.py`로 다시 생성했습니다.

프로젝트 지침에 따라 사용자가 새 펌웨어를 빌드·업로드한 뒤 한글 파일 추가,
내용 수정, 같은 이름 교체, 다운로드 내용 비교, 삭제, 재부팅, 카드 없음,
카드 쓰기 실패를 확인합니다. 두 브라우저에서 같은 파일을 연 뒤 한쪽만 먼저
저장하면 다른 쪽은 충돌을 표시하고 편집 내용을 보존해야 합니다.
