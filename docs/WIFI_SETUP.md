# 모든 Mini WebServer 펌웨어의 SoftAP 설정

C3, S3, M1, S3-N16R8-SD, P4에 같은 웹 설정을 적용했습니다.

1. 처음 전원을 켜거나 저장된 공유기 연결에 실패하면 `Mini-WebServer-Setup` Wi-Fi가 열립니다.
2. 휴대전화·PC를 이 Wi-Fi에 연결하고 `http://192.168.4.1/setup`을 엽니다. 인터넷 없음 안내가 나와도 연결을 유지하세요.
3. 주변 Wi-Fi를 검색해 선택하거나 숨겨진 SSID를 직접 입력합니다. 비밀번호를 입력합니다.
4. 서버 IP를 **자동 할당(DHCP)** 또는 **고정 IP 직접 지정** 중에서 선택합니다.
5. 저장하면 보드가 재시작하고 설정한 공유기에 연결합니다. 휴대전화·PC도 같은 공유기에 연결한 뒤 안내된 주소를 엽니다.

고정 IP 예시: 공유기가 `192.168.0.1/24`인 경우, 사용하지 않는 `192.168.0.50`, 게이트웨이 `192.168.0.1`, 마스크 `255.255.255.0`, DNS `192.168.0.1`. DNS를 비우면 게이트웨이를 사용합니다. IP가 이미 사용 중인지 보드가 검사하지는 않으므로 공유기 DHCP 범위 밖 주소 또는 예약 주소를 사용하세요. 자동 할당으로 되돌리면 이전 고정 주소를 지우고 DHCP를 다시 시작합니다.

여기서 지정하는 IP는 **공유기에 연결한 후 웹 서버가 사용할 IPv4**입니다. 설정용 SoftAP는 복구 주소를 일정하게 유지하기 위해 `192.168.4.1/24`를 사용합니다. 고정 IP의 서브넷이 이 대역과 겹치면 저장하지 않습니다. 공유기 LAN이 192.168.4.0/24라면 DHCP를 사용하거나 공유기 대역을 변경하세요.

Wi-Fi 이름은 UTF-8 1~32바이트, 비밀번호는 8~63바이트 또는 빈 값(개방형 Wi-Fi)입니다. IP·게이트웨이·마스크·DNS를 서버에서도 검사하며, 잘못된 입력은 저장하지 않습니다. 비밀번호와 IP 설정은 하나의 NVS 레코드로 저장됩니다. 이전 펌웨어의 Wi-Fi 설정은 읽어서 계속 사용할 수 있습니다. 웹 설정 조회에는 저장된 비밀번호를 반환하지 않습니다. 다시 설정할 때는 Wi-Fi 비밀번호를 다시 입력하세요.

연결된 LAN에서도 `/setup`을 열 수 있습니다. 저장할 때 관리자 비밀번호가 필요하며, 관리자 세션으로 로그인한 상태라면 그대로 사용할 수 있습니다. 주변 Wi-Fi 검색·기존 설정 조회는 설정용 SoftAP에 직접 연결하거나 관리자 세션으로 로그인해야 사용할 수 있습니다. 초기 SoftAP는 비밀번호가 없는 근거리 설정망입니다.

M1은 초기 설정과 연결 실패 시 SoftAP 화면을 자동으로 엽니다. LCD의 기존 Wi-Fi 선택·키보드·공유기 모드 기능도 유지합니다. P4는 ESP-Hosted로 C6 무선 칩을 사용하며, 호환되는 C6 펌웨어 설치가 필요합니다. [P4 설치 안내](<../mini-WEB (P4-ESP-IDF_ver)/README.md>)를 확인하세요.

## 소스와 검증

- `tools/firmware_common/wifi_setup.html`: 공통 반응형 설정 화면
- `tools/firmware_common/network_settings.inc`: 입력 검증, NVS 저장·이전 설정 호환, DNS/IP 적용
- `tools/firmware_common/web_network_setup.inc`: 설정 조회·Wi-Fi 검색·저장 API
- `python tools/sync_network_setup.py`: 각 프로젝트에 독립적으로 사용할 복사본과 내장 HTML 생성
- `node tools/test_network_setup.cjs`: 실제 화면 JavaScript의 입력·실패·저장 흐름 및 다섯 프로젝트의 연결 지점 검사

저장소 규칙에 따라 에이전트는 펌웨어를 컴파일하거나 설치하지 않습니다. 호스트 검증과 실물 검증은 별개입니다. 사용자 빌드 후 SoftAP 접속, WPA2 공유기 연결, 고정 IP/DNS 적용, DHCP 복귀, 잘못된 비밀번호에서 SoftAP 복구, 재부팅 후 설정 유지, P4의 C6·SD 동시 동작을 확인하세요.
