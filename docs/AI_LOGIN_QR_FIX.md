# AI 로그인·QR 오류 수정

S3와 C3 소스에 동일하게 적용했습니다.

- AI 로그인 스크립트의 문자열 안에 잘못 삽입된 코드를 제거했습니다. 이 문법 오류가 로그인, 테마 전환, 비밀번호 보기, 실패 횟수 조회를 모두 중단시켰습니다. 내부 HTML 교체 문자열은 스크립트 태그 문자열을 분리해 같은 삽입 오류를 피하도록 수정했습니다.
- 관리자·AI 초기 비밀번호는 00000000입니다. 이전 기본 0000은 평문·해시 저장 형식 모두 전환합니다. 실제로 변경한 사용자 비밀번호와 저장된 키는 임의로 지우지 않습니다. 기존 사용자 비밀번호가 있으면 해당 비밀번호를 사용해야 합니다.
- API 키 저장·교체 버튼을 유지하고, 요청 보내기를 누르면 입력란의 새 키를 먼저 저장한 뒤 대화를 처리하도록 추가했습니다. 로그인 비밀번호 자체를 브라우저 저장소에 저장하지 않는 보안 정책은 유지됩니다.
- 관리자 로그인·비밀번호 변경과 AI 로그인에서 보기 버튼을 입력칸 옆으로 배치했습니다.
- 예제 목차의 외부 QR 라이브러리를 제거하고 보드의 /api/qr SVG 이미지를 사용합니다. 인터넷 연결 없이 보드 Wi-Fi에서 표시할 수 있습니다. PC의 파일 미리보기에서는 보드에 업로드하라는 안내를 표시합니다.
- QR API가 URL 인코딩을 해제하고 더 긴 주소에 대응하도록 QR 버전 10까지 지원합니다. SVG 경로를 묶어서 전송해 작은 HTTP 응답 조각을 줄였습니다.
- web_examples/index.html, linked_test_package/upload/index.html 및 linked_test_package.zip을 갱신했습니다. 기존에 올린 예제 index.html도 새 파일로 교체해야 합니다.

검사: 관리자·AI 로그인·AI 화면의 내장 JavaScript에 대해 정적 문법 검사를 통과했습니다. 펌웨어 빌드·플래시 및 실제 보드 동작 시험은 실행하지 않았습니다. 기존 firmware_upload/2026-10-02의 BIN에는 이번 변경이 포함되지 않으므로 다시 빌드·업로드해야 합니다.
