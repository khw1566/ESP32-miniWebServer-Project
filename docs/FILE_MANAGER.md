# 관리자 파일 관리

## 적용 대상

- 웹 저장소: M1, S3, C3, S3-N16R8-SD.
- SD 카드: M1, S3-N16R8-SD.

## 사용 방법

파일 옆의 체크박스로 파일을 선택합니다. 제목 행의 체크박스는 현재 표시된 파일을 선택합니다. 웹 저장소의 검색·날짜 필터를 사용하면 필터 결과만 전체 선택합니다.

`선택 파일 저장`은 선택한 파일을 하나씩 다운로드합니다. 브라우저가 여러 파일 다운로드를 차단하면 해당 사이트의 다운로드 권한을 허용하세요. 개별 파일의 `저장` 버튼은 해당 파일만 다운로드합니다.

`선택 파일 삭제`는 확인 후 선택한 파일을 하나씩 삭제합니다. 일부 작업이 실패해도 나머지 파일을 계속 처리합니다. 성공한 파일은 선택에서 해제하며, 실패한 파일은 선택 상태를 유지합니다.

SD 폴더는 삭제 대상으로 선택할 수 없습니다. 같은 폴더의 페이지를 이동해도 파일 선택은 유지됩니다. 다른 폴더로 이동하면 선택을 해제합니다.

SD 목록은 페이지당 24개를 표시합니다. 온보드 화면의 3개 표시 제한은 유지됩니다. `내용 보기`는 1 MiB 이하의 텍스트·이미지를 새 창에서 표시합니다. HTML과 JavaScript는 텍스트로 표시합니다.

## SD 백그라운드 조회

서버가 실행 중이고 HTTP 연결이 10초 동안 없으면 파일명, 크기, 폴더 정보를 미리 조회합니다. 파일 본문은 미리 읽지 않습니다. 서버에 연결이 생기면 사전 조회를 중지합니다.

사전 조회는 내부 RAM 여유가 64 KiB 이상일 때 진행합니다. 목록 메모리를 늘릴 때는 추가 메모리까지 확인합니다. 최대 192개 항목을 저장합니다. 내부 RAM 여유가 48 KiB 미만이면 목록 메모리를 해제합니다.

SD 업로드 또는 삭제 후에는 이전 목록을 사용하지 않습니다. 클라우드 업로드 완료도 같은 규칙을 적용합니다. 목록은 다음 유휴 시간에 다시 조회합니다. 유휴 상태에서는 60초마다 목록을 다시 확인합니다.

RAM 부족, 항목 상한 초과 또는 조회 오류로 목록을 완성하지 못하면 SD 카드를 직접 조회합니다. 이 경우에도 전체 폴더를 24개씩 확인할 수 있습니다. 응답은 파일별로 나누어 전송합니다.

## 검증

`node tools/test_file_manager.cjs`는 네 종류 관리자 스크립트의 구문과 선택·다운로드·부분 삭제 실패를 검증합니다. SD 페이지 크기, 세션 인증, 폴더 전환 및 사전 조회 보호 조건도 확인합니다. SD 보호 조건 검사는 소스 검사이며, 보드 실행 검증을 대신하지 않습니다.

기존 SD 관리자 테스트, 관리자 조회 중복 방지 테스트 및 M1 메모리 정책 테스트도 실행했습니다.

프로젝트 지침에 따라 펌웨어 빌드·업로드는 실행하지 않았습니다. 사용자가 대상 보드의 펌웨어를 빌드·업로드한 뒤 실제 SD 카드에서 동작을 확인해야 합니다.
