# S3 / C3 공통 펌웨어 동기화

## 반영 내용

- 관리자 화면을 S3의 6개 탭(모니터, 파일, QR 접속, OTA, 설정, 로그)으로 통일.
- 웹 저장소 전체 삭제 및 기본값 복원 유지. 관리자 비밀번호 0000, 기본 첫 화면, 사용자 지정 메인 해제. Wi-Fi 정보와 펌웨어 유지.
- 파일별 메인 화면 지정, 시스템/웹 저장공간 그래프, QR 및 IPv6 재시도, OTA, 로그, 모바일 설정 UI를 같은 소스로 통일.
- C3의 설정 요청 버퍼 768 bytes, 경로 길이 검증, QR 오류 표시, IPv6 재시도 응답을 공통 소스에 반영.
- S3의 로그 길이 제한 및 잠금 대기 없는 로그 처리, 관리자 비밀번호 읽기 방어, 저장소 복구 시점을 C3에 반영.
- AI 화면/도구 및 미디어 Range 처리 파일은 비교 당시 이미 동일.

## 공통 소스

두 프로젝트 main의 web_page_admin.c, web_server.c, web_page_static.c, network_manager.c, dns_server.c를 동일하게 맞췄습니다. 웹서버는 파티션 테이블에서 보드별 저장공간을 조회합니다. main.c의 보드명, sdkconfig, 파티션, 빌드 출력은 보드별로 유지합니다.

## 적용

프로젝트 지침에 따라 펌웨어 빌드·플래시는 실행하지 않았습니다. S3와 C3 프로젝트에서 각각 빌드·업로드해야 보드에 적용됩니다. 기존 웹 파일을 삭제하거나 초기화를 실행한 작업은 없습니다. 초기화는 관리자 화면에서 사용자가 실행할 때만 동작합니다.
