# AI 디자인·로그인 안내 개선

S3와 C3 소스에 동일하게 적용했습니다.

- AI 스튜디오와 로그인 화면에 백·회·청 일반 모드 및 흑·회·청 다크 모드를 제공합니다. 관리자 화면과 같은 브라우저 테마 설정을 공유합니다. 그라데이션 및 다색 차트를 단색 청색과 회색 계열로 변경했습니다.
- AI·관리자 로그인 화면과 관리자 보안 설정에서 현재 실패 횟수, 누적 실패 횟수, 재시도 대기 시간을 표시합니다. 기록 최신화 버튼으로 다시 조회할 수 있습니다.
- 관리자와 AI의 비밀번호 실패 횟수를 공유합니다. 5회 실패하면 60초 동안 제한하고 로그인 버튼에 대기 상태를 반영합니다. 정상 인증 후 현재 실패 횟수는 0으로 돌아갑니다.
- 누적 횟수는 별도 NVS auth_audit 영역에 저장하여 재부팅과 웹 저장소 초기화 후에도 유지합니다. 현재 제한 횟수와 대기 시간은 재부팅 시 초기화됩니다. 처음 적용하는 시점 이전의 실패 기록은 소급할 수 없습니다. 보드 전체의 합산 기록이며 사용자·IP별 기록은 아닙니다.
- 기록 저장 실패 시 표시하고, 기록을 읽지 못한 경우 기존 NVS 기록을 덮어쓰지 않습니다.
- AI·관리자 로그인 및 비밀번호 변경 입력란에 보기·숨기기 버튼을 추가했습니다. 실패한 AI 로그인 입력을 유지해 오타를 확인할 수 있게 했습니다. 성공하면 지우며 입력한 비밀번호는 실패 기록에 저장하지 않습니다.
- AI 로그인·키 저장·대화·파일 도구 오류 및 화면의 영어 버튼·상태 안내를 한국어로 변경했습니다. 모델 ID, API 경로, 파일명처럼 처리에 필요한 식별자는 유지합니다.

이번 요청에서는 빌드·플래시 및 기능 시험을 실행하지 않았습니다. 변경 사항을 사용하려면 두 펌웨어를 다시 빌드·업로드해야 합니다. firmware_upload/2026-10-02에 이전 요청으로 생성한 BIN에는 이번 변경이 포함되지 않습니다.
