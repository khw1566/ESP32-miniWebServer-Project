# 2026-10-24 M3 통합 기준

현재 M3 소스의 복구 기준은 `origin/restore/2026-10-22`의
`43cf3baefeb0a06128f71ef604f5386f12924706`이다. 브랜치 이름의 날짜와 달리
2026-10-24 변경까지 포함한다. `local-sync-2026-10-17`의 `1fb6d9b`와
`main`의 `bf7bf06`에는 이후 M3 기능이 모두 들어 있지 않다.

로컬 통합 브랜치는 `codex/integrate-m3-latest-20261024`이다. 최신 테마,
움직이는 배경화면, GIF/MP4, 압축 글꼴, Flash 사용량 기능 위에 다음을 통합했다.

- SD `.private/relays.json`의 여러 HTTPS 서버·토큰 자동 선택
- PC 중계서버의 다중 토큰 승인, SD 설치 도구와 트레이 최소화
- 여러 Wi-Fi 프로필의 스캔·선택 흐름과 STA 종료 확인·중복 START 방지

기존 SD 키·Wi-Fi·중계 설정은 유지한다. M4는 다른 채팅에서 진행 중인 독립
작업이므로 이 통합 커밋의 변경 대상에 넣지 않았다. GitHub 푸시도 수행하지 않았다.

호스트 검사 및 실제 ESP-IDF 플래그를 사용한 `-fsyntax-only` 검사를 통과했다.
펌웨어 전체 빌드·링크·업로드와 새 소스의 실기 부팅·재생은 별도 확인이 필요하다.
기존 `build/`의 바이너리 날짜만 보고 새 소스의 빌드 결과로 판단하지 않는다.

다음 작업 전에 `git branch --show-current`, `git log -1`, `git status --short`를
확인한다. `git fetch`는 원격 정보를 갱신하며 작업 브랜치를 바꾸지 않는다.
SD 비밀 설정, 빌드 결과, 임시 파일은 계속 Git에서 제외한다.
