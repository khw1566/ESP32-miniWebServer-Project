# AI 미디어 분석과 보드 문제 진단

S3, C3, M1의 AI Assistant에 공통으로 적용합니다. 관리자 인증 후 저장된 Gemini 키로 사용합니다.

## JPG 및 MP4 분석

1. 관리자 파일 화면에서 JPG/JPEG, PNG, WebP 또는 MP4를 보드에 업로드합니다.
2. AI Assistant에서 `미디어 목록`을 누르고 파일을 선택합니다.
3. `분석 요청 작성`을 누르면 입력란에 요청이 작성됩니다. 원하는 질문을 추가한 뒤 `요청 보내기`를 누릅니다.
4. 채팅에서도 `photo.jpg를 읽고 화면에 무엇이 보이는지 설명해줘`처럼 파일명을 지정할 수 있습니다.
5. 영상의 특정 시점은 `clip.mp4의 5초, 50초, 90초 화면을 분석해줘`처럼 요청합니다. 모델이 `inspect_media`의 `timestamps` 인자로 지정합니다.

보드 저장 파일은 경로 없이 24자 이하 영문·숫자·점·하이픈·밑줄 이름을 사용합니다. 파일당 최대 8 MiB이며 저장 파티션 용량이 더 작으면 그 용량 안에서 업로드해야 합니다. 이미지는 브라우저에서 JPEG로 축소합니다. MP4는 기본 10%, 50%, 90% 시점에서 최대 3개 화면을 추출합니다. 사용자가 지정한 시점은 영상 길이 범위 안이어야 합니다.

MP4 분석은 화면 표본 분석입니다. 음성, 자막 음성 전사, 전체 영상의 모든 사건을 분석하지 않습니다. 작은 글씨나 빠른 장면은 축소·샘플링 과정에서 놓칠 수 있습니다. 브라우저가 해당 MP4 코덱을 재생할 수 있어야 합니다. 디코딩·프레임 추출은 브라우저가 수행하므로 AI 화면을 열어 두세요.

Gemini에는 파일명만 보내는 것이 아니라 실제 JPEG 이미지 데이터를 보냅니다. 보드의 요청 한도 48 KiB를 유지하며 이미지당 base64 16,000자, 영상 프레임당 6,000자, 한 도구 단계의 표본 합계 24,000자를 제한합니다. 요청 전체가 크거나 보드 메모리가 부족하면 명시적인 오류를 표시합니다. 여러 파일은 하나씩 분석하고 필요하면 새 대화를 시작하세요. 이전 대화의 이미지 데이터는 다음 요청에서 생략되며 필요 시 도구로 다시 읽습니다.

외부 URL 및 PC 파일을 자동으로 읽지 않습니다. 현재 파일 경로는 SPIFFS 저장소이며 SD 카드 지원은 포함하지 않습니다. 원본 미디어 전체 업로드 대신 표본만 보드 프록시를 통해 전송합니다. 이는 [Gemini의 이미지 입력 방식](https://ai.google.dev/gemini-api/docs/image-understanding)을 사용합니다.

## 진단 기능

`하드웨어와 네트워크 진단 정보를 조회하고 이상 징후를 알려줘` 또는 `최근 로그와 진단 정보를 함께 읽고 오류 원인과 해결 순서를 알려줘`를 요청합니다.

`get_diagnostics`는 다음 정보를 읽습니다.

- 칩 타깃·모델·리비전·코어·특징, 설정 CPU 주파수, ESP-IDF·펌웨어 버전과 빌드 시각, 리셋 원인, 플래시 용량, 실행 앱 및 파티션 구성.
- 가용·최소 힙, 최대 연속 할당 가능 블록, 내부 메모리, PSRAM 총량·가용량, SPIFFS 상태·총량·사용량·잔여량.
- Wi-Fi 모드 및 연결 상태, 연결 SSID·BSSID·RSSI·채널·인증 방식·절전 모드, SoftAP 접속 수.
- STA/AP 인터페이스 활성화, MAC, IPv4·게이트웨이·서브넷·DNS·DHCP 상태, IPv6·링크 로컬·mDNS 주소와 준비 상태.
- 부팅 이후 Wi-Fi 연결 해제 횟수와 마지막 해제 사유 코드, 가동 시간 및 TLS 시간 준비 여부. 해제 횟수에는 의도적인 연결 해제도 포함됩니다.

`get_logs`는 최근 RAM 로그 최대 4 KiB를 읽습니다. 재부팅 이전 로그는 보존하지 않습니다. 비밀번호·키·토큰 등의 알려진 표지가 포함된 줄은 마스킹하지만 임의의 사용자 로그에 포함된 모든 민감정보를 식별하는 기능은 아닙니다.

진단 조회와 로그 조회는 읽기 전용이며 Wi-Fi 재설정·재부팅·파일 삭제를 실행하지 않습니다. 사용자에게 요청받은 웹 파일 변경은 기존 도구로 수행할 수 있습니다. AI는 관측값, 추정 원인 및 확인 방법을 구분하도록 지시받습니다. 값이 정상이라는 이유만으로 인터넷·DNS·Google API 연결이 정상이라고 단정하지 않습니다. 온도·전압·GPIO 실제 측정값, SD 카드 상태는 제공하지 않습니다.

도구로 요청한 진단 값, 연결 SSID·MAC 등의 네트워크 정보, 마스킹된 로그 및 이미지 표본은 Gemini로 전달됩니다. API 키 원문, Wi-Fi 비밀번호 및 NVS 원문은 진단 도구에서 반환하지 않습니다. 보드 도구 사용 체크를 끄면 미디어·진단 조회도 중지됩니다.

## 검증과 적용

각 펌웨어 폴더에서 다음 호스트 테스트를 실행할 수 있습니다.

```text
node tools/test_ai_key.cjs
node tools/test_ai_studio.cjs
node tools/test_ai_media.cjs
```

테스트는 생성된 스크립트 문법, 인증·키 저장, 파일 도구 루프, 미디어 처리 모의 실행, 이미지 데이터 전달, 타임스탬프·크기·경로 제한 및 정리를 검증합니다. 실제 브라우저 코덱, Gemini 응답과 하드웨어 진단 값은 보드에서 별도 확인이 필요합니다. 프로젝트 규칙에 따라 에이전트가 펌웨어 컴파일·플래시를 실행하지 않습니다.
